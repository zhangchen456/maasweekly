## 一、重要更新摘要

### 🔴 本周头条

1. **GPT-5.6 有限预览发布，三模型系列 Sol/Terra/Luna 登场**
   - 6月26日，OpenAI 宣布开始有限预览 GPT-5.6 系列模型：旗舰模型 Sol、平衡型 Terra、低成本 Luna。Sol 在编程、生物学和网络安全任务上有提升。引入新 max 推理强度和 ultra 子智能体模式。定价：Sol $5/$30、Terra $2.5/$15、Luna $1/$6（每百万 token）。初期仅通过 API 和 Codex 向少数可信伙伴开放，参与方信息已与美国政府共享。GPT-5.6 Sol 将于 7 月登陆 Cerebras，最高 750 token/s。原定 6/22-28 全量发布窗口因特朗普政府审查推迟。

2. **豆包大模型 2.1 Pro 正式发布，Coding/Agent/VLM 跨越"质变点"**
   - 6月23日 FORCE 大会发布。Terminal Bench 2.1、SWE-Pro、SciCode 等代码评测进入第一梯队，多项优于 Claude Opus 4.6。芯片设计 RTL 实测连续运行 18 小时完成 1303 行代码。500 个 Agent 同步协作生成 3D 虚拟城市。定价：每百万 Tokens 输入 6 元、输出 30 元，缓存命中 1.2 元，综合成本较 Claude Opus 4.6 降低近 80%。日均 Token 调用量突破 180 万亿（年增 10 倍）。同步发布 Seedance 2.5（视频）、Seedream 5.0 Pro（图像）、Seed-Audio 1.0（音频），付费订阅四档正式上线。

3. **DeepSeek V4.1 正式发布，500 亿元首轮融资创纪录**
   - V4.1 首次支持文本+图像+音频全模态输入，MCP 协议深度适配（从"能调用工具"到"可靠调用工具"），企业级工具链（模型微调、私有化部署、访问控制、MCP 网关）。V4.1 Flash 代码能力"天差地别"提升，知识截止日期从 2025年5月跃升至 2026年1月。V4-Pro API 永久降价 75%。首轮融资约 500 亿元（~$7.5B），投后估值近 4000 亿元。创始人梁文锋出资 200 亿元，腾讯 100 亿元，宁德时代约 50 亿元。从"不融资"转向商业化转型。

4. **Kimi Work 推出目标模式（Goal Mode），支持 300 个 Agent 集群协作**
   - 6月18日上线。设定完成条件后 AI 持续工作，每轮自动检查是否达标。支持连续工作 24 小时以上。Agent 集群模式最多调度 300 个 Agent 并行协作。实测：SVG 复刻从 59% 迭代至 99.9998%，71 章节 650 页漫画书制作，一键 GitHub 开源仓库。与 Claude Code /goal、Codex /goal 对标但门槛更低。

5. **百度千帆发布 Token Plan 企业版，Coding Plan 套餐升级**
   - 6月24日发布企业级 AI 生产力订阅服务，支持聚合 DeepSeek-V4、GLM-5、Kimi-K2.6 等多厂商模型。覆盖代码开发、智能办公、知识管理、Agent 构建等场景。6月25日起现有 Coding Plan 停止续费，7 月初通过 Token Plan 提供更丰富选择。文心网站同步全面升级为统一超级入口，Unlimited OCR 模型开源（OmniDocBench v1.6 基准 93.92%）。

6. **硅基流动完成超 20 亿元 B 轮融资**
   - 6月16日完成，创 2026 年国内第三方 MaaS 平台单笔融资最高纪录。投资方包括携程战投、晶科能源、金蝶股份、联通新沃、壁仞战投、蔚来资本、商汤战投等。日均 Token 调用量达数万亿，营收同比增长超 10 倍，海外市场单月营收达数百万美元。本周上线 Nex-N2-Pro 模型（Agentic Thinking）。

## 四、趋势洞察

1. **AI 监管从"硬件管制"扩展到"模型审查"已成定局**
   - GPT-5.6 因特朗普政府要求审查被迫以"有限预览"方式发布，参与方信息需与政府共享。Anthropic Fable 5/Mythos 5 遭出口管制全面封禁。前沿 AI 模型的发布已从"技术竞赛"全面转向"合规竞赛"，模型审查可能成为常态化机制。OpenAI 称"这不是希望长期采用的默认发布方式"，反映出厂商对监管不确定性的担忧。

2. **国产大模型首次在 Coding 与 Agent 领域明确超越国际标杆**
   - 豆包 2.1 Pro 在 Terminal Bench 2.1、SWE-Pro、SciCode 等评测中优于 Claude Opus 4.6，火山引擎明确宣布"跨越生产级质变点"。DeepSeek V4.1 补齐多模态+MCP+企业级能力，从"纯文本技术标杆"向"全模态 AI 基础设施"转型。国产大模型从"追赶"进入"并跑甚至领跑"阶段，定价仅为国际竞品的 1/5-1/4。

3. **Agent 能力从"任务执行"迈向"目标驱动"，大规模并行协作成新竞争维度**
   - Kimi Work 目标模式支持 300 个 Agent 集群并行协作，可连续工作 24 小时。豆包 2.1 Pro 实现 500 个 Agent 同步协作生成 3D 虚拟城市。从"human in loop"到"定义终点即可"，Agent 自主性大幅提升。GPT-5.6 引入 ultra 子智能体模式。"目标驱动"模式将成为下一代 AI 产品标配能力。

4. **国产大模型平台"统一入口+聚合服务"趋势深化**
   - 百度千帆 Token Plan 企业版聚合 DeepSeek-V4、GLM-5、Kimi-K2.6 等多厂商模型。百度文心网站合并升级打造统一超级入口。腾讯 TokenHub 统一售卖入口。平台从"单一模型服务"向"多模型聚合服务"转型，降低企业接入门槛。API 兼容性管理和迁移引导成为平台必修课。

5. **融资加速商业化转型，大模型进入资本密集期**
