01DeepSeek头条DeepSeek V4 发布并开源（4月24日）

— V4-Pro 拥有1.6T总参数、49B激活参数，V4-Flash 284B/13B，上下文1M token，MIT开源授权。引入 CSA/HCA 混合注意力机制，KV Cache降至V3.2的10%，推理FLOPs降至27%。全面适配华为昇腾950PR芯片，训练框架从英伟达迁移到华为。启动首次外部融资，目标估值从$100B升至$200-300B，腾讯、阿里正洽谈入局。V4-Pro限时75%折扣延长至5月31日。

02Kimi头条Kimi K2.6 发布并开源（4月20日）

— 1T总参数（激活32B），业界总参数量最大的开源模型，256K上下文。Agent集群架构支持300个子Agent并行协作、4000次协调步骤。在HLE、BrowseComp、SWE-Bench Pro超越GPT-5.4。投前估值$180B（约1200亿人民币），新一轮$1B融资进行中。API输入价格从4元/百万token涨至6.5元（涨幅58%），首次涨价。海外收入已超越国内，付费用户月环比增速超170%。

03腾讯混元头条腾讯混元 Hy3 Preview 发布并开源（4月23日）

— 295B总参数（激活21B），256K上下文，快慢思考融合MoE架构（192路专家top-8路由）。首Token延迟降低54%，端到端时长降低47%。SWE-Bench Verified 74.4%，清华数学博士资格考试国内最高分。姚顺雨主导技术重构后首份答卷，腾讯AI从"被动"转向"能打"。4月29日登顶OpenRouter API调用量榜首，工具调用排名全球第1、编程排名全球第2。

04MiniMax头条MiniMax M2.7 发布

— 自演化模型，参与自身进化，能构建复杂Agent Harness。SWE-Pro 56.22%（接近Opus水平），GDPval-AA ELO 1495（开源最高）。Day 0实现六芯落地（平头哥、华为、海光、沐曦、天数、英伟达）。同步发布Music 2.6、Speech 2.8、Hailuo 2.3。自进化工作流超100轮迭代循环实现30%性能提升。

05智谱AI头条智谱AI发布 GLM-5V-Turbo

— 首个多模态Coding基座模型，从预训练阶段深度融合视觉与文本能力。支持草图、风格参考、截图、录屏等图像输入生成可运行代码。AutoClaw、Z.ai平台、BigModel开放平台同步开放体验。

06头条阿里云发布 HappyHorse（快乐小马）AI视频生成模型

— 150亿参数单流Transformer架构，原生音视频同步生成。单张H100生成5秒1080P视频仅需38秒，速度达行业主流2-3倍。支持中英日韩德法粤7种语言唇形匹配。匿名登顶Artificial Analysis Video Arena盲测榜单。定价720P 0.9元/秒，1080P 1.6元/秒。

07头条Grok 4.3 API 发布（4月30日）

— 输入价格降低40%至$1.25/百万token，1M上下文，支持原生视频输入和PDF/XLSX/PPTX文档输出。Heavy系统升级为16-Agent并行调度。Voice API STT/TTS $4.20/百万字符，比OpenAI便宜86-92%。AA Intelligence Index 53。
