01智谱头条新增智谱GLM-5.3正式发布——8月14日发布，"同基座纯后训练"路线，编程开源第一，网络安全能力意外涌现

8月14日13:36，智谱正式发布GLM-5.3。关键信息：

① 同基座纯后训练：GLM-5.3与GLM-5.2共用同一基座（7430亿参数），未增加一个参数，全部能力提升来自后训练Scaling——数十倍的长程任务环境、更丰富多样的环境类型、超长的后训练时间。基于IndexShare（长上下文）、SAO（长程任务强化学习）与新一代Slime大规模异步训练框架。

② 编程能力开源第一：在内部Z.ai Code Bench中较GLM-5.2提升50%。Terminal-Bench 3.0从4.6跃升至28.3，DeepSWE v1.1从46.2提升至66.9，Agents' Last Exam从23.8提升至28.5。在High档位下达到31.4%准确率，超过Claude Opus 4.8最高档位的29.5%，且每任务平均输出约5万tokens（Opus 4.8需约12万tokens）。

③ 网络安全能力意外涌现：CyberGym从77.2%提升至84.5%，略高于Mythos 5的83.8%和GPT-5.6 Sol的83.6%。ExploitBench从24.4%翻倍至54.4%。发布前联合清华、南开等开展红队测试，在269个项目中发现2436个有效漏洞，其中最早的bug已潜伏40年（DNS协议级风险）。启动"开源的盾"计划，向开源项目提供持续安全审计。

④ 权重两周后开源：完整模型权重将在发布两周后（约8月28日）开放，此前需完成安全评估与模型加固。对敏感能力实施"可信访问"分层授权机制。

⑤ 多平台同步上线：即日起上线ZCode、AutoClaw，GLM Coding Plan全量用户开放。TraeWork/TraeCode/扣子、WorkBuddy/CodeBuddy、Qoder/QwenWork、CatPaw、JoyCode、OpenCode等平台开放抢先体验。API随后上线。

与此前报道的差异：此前8月14日报告提及"百度百科GLM-5.3词条已创建，发布窗口已打开"，本报告确认GLM-5.3已于8月14日当天正式发布。命名确认为GLM-5.3（非GLM-5.5），参数维持7430亿（非此前预期的"破万亿"），升级路线为"同基座+后训练Scaling"而非增大参数规模。（跟进报道GLM-5.3：2026-08-14/08-11/08-07/08-04）

02DeepSeek头条跟进DeepSeek API峰谷新定价8月17日0时正式生效——V4-Pro缓存命中输入涨幅高达1100%，"缓存命中率越高涨得越狠"反直觉结论引关注

8月17日0时，DeepSeek V4系列API全新定价正式生效。关键信息更新：

① 峰谷定价细节：高峰时段为工作日9:00-12:00和14:00-18:00，空闲时段价格为高峰的一半。V4-Pro缓存命中输入从0.025元涨至高峰0.30元（涨幅1100%）、空闲0.15元（涨幅500%）；缓存未命中输入从3元涨至高峰9元（涨幅200%）、空闲4.5元；输出从6元涨至高峰27元（涨幅350%）、空闲13.5元。V4-Flash缓存命中输入从0.02元涨至高峰0.10元（涨幅400%）、空闲0.05元；缓存未命中输入从1元涨至高峰3元（涨幅200%）、空闲1.5元；输出从2元涨至高峰9元（涨幅350%）、空闲4.5元。

② 开发者实测揭示反直觉结论：GitHub开发者KevinZhangMe用650次请求（613次v4-pro，缓存命中率98.09%）与DeepSeek官方账单对账后发现：同样token按新价重算，账单变为原来的2.7倍。缓存命中率越高，这次涨价越不实惠——因为涨得最狠的是最便宜的缓存命中输入档（涨6倍），而非输出档（涨2.3倍）。但缓存仍然是最大杠杆：同样负载下，缓存把本该¥711.73的账单压到¥46.53，省下¥665.21。

③ 时段杠杆对中国开发者不友好：高峰窗口北京时间9:00-12:00和14:00-18:00正好卡在标准工作日。实测显示41.1%的token落在高峰计费时段。美东/美西的9am-5pm反而几乎全落在空闲段。开发者建议：能等的批量任务挪到午休或晚上，不改一行代码就能拿五折。

④ 行业意义：DeepSeek从"价格屠夫"转向"价值定价"，标志着大模型API"低价时代"逐步落幕。DeepSeek率先引入"电力式"峰谷定价，引导用户错峰调用，缓解算力资源高峰压力。（跟进报道涨价预告：2026-08-14/08-11）

01. 后训练Scaling成为新范式——智谱GLM-5.3"不增一参数"实现50%编程能力提升

GLM-5.3的最大意义不在于具体分数，而在于其验证了一条新路线：在完全相同的7430亿参数基座上，仅通过后训练Scaling（IndexShare+SAO+Slime框架）就实现了编程能力50%的提升和网络安全能力的意外涌现。这打破了"能力提升必须增大参数"的惯性思维。Terminal-Bench 3.0从4.6到28.3的跃升（6倍提升）表明，基座模型的智能上界可能远未被充分开发。如果这条路线被验证可持续，行业竞争焦点将从"谁的参数更大"转向"谁的后训练更高效"。

02. DeepSeek涨价后的开发者生态反应——实测工具涌现，错峰策略成为必修课

DeepSeek峰谷定价生效后，GitHub开发者迅速发布了对账审计工具（dsh-cache-audit.py），揭示了"缓存命中率越高涨得越狠"的反直觉结论。这一发现促使开发者重新思考缓存策略：缓存仍是最大杠杆（省93%+），但杠杆效率从6倍降至2.7倍。时段杠杆则对中国开发者特别不利——41%的token落在高峰时段。社区已开始推广错峰调度策略：批量任务挪到午休或晚上可拿五折。这种精细化的成本管理正在成为DeepSeek开发者的"必修课"。

03. MaaS平台从"模型调用"向"Agent基础设施"演进——阿里百炼Managed Agent商业化标志行业拐点

阿里百炼Managed Agent 8月17日正式商业化，加上Knowledge Studio发布、MCP广场39个新模板、记忆库商业化，百炼正在从"模型API调用平台"演进为"Agent基础设施平台"。这与DeepSeek Harness的"一切皆插件"理念、智谱GLM-5.3的多平台编码工具上线、Kimi Code v0.36.0的子Agent模型池配置功能形成共振——所有头部MaaS平台都在向Agent基础设施方向演进。竞争焦点已从"谁的模型更强"扩展为"谁的Agent基础设施更完善"。

04. GLM-5.3网络安全能力涌现——大模型从"工具"向"专业工作者"转变

GLM-5.3在CyberGym上达84.5%（超Mythos 5和GPT-5.6 Sol），发现潜伏40年的DNS协议漏洞，这一能力涌现具有标志性意义。它意味着大模型不再只是"通用工具"，而是开始在特定专业领域（网络安全审计、法律分析、金融建模等）达到专业工作者水平。智谱"开源的盾"计划将这一能力开放给开源社区，可能改变网络安全审计的行业生态。

05. 8月中旬国产大模型"超级周"后续效应——GLM-5.3+DeepSeek调价+百炼产品矩阵三线并行

8月14日GLM-5.3发布、8月17日DeepSeek新定价生效、8月17日百炼Managed Agent商业化——三个事件在同一周内密集发生，各自代表不同方向：GLM-5.3代表"模型能力突破"（后训练Scaling）、DeepSeek代表"商业模式重构"（价值定价）、百炼代表"平台基础设施演进"（Agent基础设施）。这三条线并行推进，标志着国产大模型行业正从"单维度竞争"（比模型分数）进入"多维度竞争"（模型能力+商业模式+平台基础设施）。
