本周头条
01头条百度文心5.1正式发布，预训练成本仅业界6%

— 采用"多维弹性预训练"技术，以仅约6%的业界同规模预训练成本实现基础能力全面领先。总参数压缩至约1/3、激活参数压缩至约1/2。LMArena搜索榜1223分国内第一、全球第四，Agent能力超越DeepSeek-V4-Pro，创意写作与Gemini 3.1 Pro同等水平。已在百度千帆、文心一言官网上线，API调用model_name为ernie-5.1。

02头条百度Create 2026 AI开发者大会，李彦宏提出DAA新度量衡

— DAA（Daily Active Agents，日活智能体数）对应移动互联网DAU，李彦宏认为Token只代表成本不代表收益，DAA才是衡量平台繁荣核心指标，预测全球DAA可能超100亿。百度智能云全面升级为"新全栈AI云"，从传统MaaS进化为"MaaS+Agent"平台，构建"芯-云-模-体"全栈能力，Agent Infra可节省23% Token消耗、任务成功率超95%。昆仑芯P800国产AI芯片出货量前三，天池256卡超节点6月上市。自研Agent产品矩阵：百度搭子DuMate、秒哒、伐谋、一镜。

03DeepSeek头条DeepSeek首轮融资目标500亿元，梁文锋自掏200亿，V4.1定档6月

— 首轮融资目标最高500亿人民币（约73.5亿美元），估值飙升至约515亿美元（约3500亿人民币），21天翻5倍创中国AI融资纪录。梁文锋个人出资200亿占本轮40%，国家大基金领投、腾讯参投。从"不融资、不商业化、不路演"转向主动寻求外部融资，计划推出企业产品实现收入正增长。V4.1定档6月发布，聚焦Agent方向。

04MiniMax头条MiniMax M1发布，全球首个开源大规模混合架构推理模型

— 支持业内最高100万上下文输入（与Gemini 2.5 Pro持平，是DeepSeek R1的8倍），业内最长8万Token推理输出。闪电注意力机制为主的混合架构，8万Token深度推理只需DeepSeek R1约30%算力。提出CISPO强化学习算法比DAPO收敛快一倍。整个RL阶段仅用512块H800三周，租赁成本仅53.47万美金。长上下文理解超越所有开源模型、超越OpenAI o3和Claude 4 Opus全球第二。

05DeepSeek头条DeepSeek V4 API正式全量开放，百万上下文成标配

— V4-Pro（1.6T/49B）和V4-Flash（284B/13B）全系标配1M上下文，完整开源无功能阉割。支持非思考模式与思考模式切换、reasoning_effort参数自定义思考强度、Json Output/Tool Calls/对话前缀续写。针对Claude Code、OpenClaw、OpenCode、CodeBuddy等主流Agent产品专项优化。V4-Flash缓存命中输入0.2元/百万token，V4-Pro缓存未命中输入12元/百万token。

06Kimi头条Kimi发布WebBridge浏览器自动化插件

— AI Agent可像人类一样操作浏览器，支持搜索、点击、输入、滚动、数据提取。本地优先架构通过Chrome DevTools Protocol运行，所有浏览数据留在本地不经过云端。支持已登录会话和敏感企业数据，兼容Kimi Code CLI、Claude Code、Cursor、Codex、Hermes。底层Kimi K2.6 SWE-Bench Pro 58.6%超越GPT-5.4的57.7%。

07头条阿里千问与淘宝全面打通，全球首个AI购物全链路闭环

— 千问App内对话完成商品挑选、对比、下单购买，淘宝App内"千问AI购物助手"提供AI试穿、AI算优惠、AI低价帮抢。全球超大规模电商平台与顶级大模型首次深度融合，基于40亿商品库的自然语言购物体验，以Agentic AI替代传统关键词搜索购物模式。

08硅基流动关注硅基流动完成近亿元天使+轮融资
