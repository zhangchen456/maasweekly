本周头条
01头条腾讯云 TokenHub 成为 DeepSeek-V4 正式版"原厂直供"渠道

（7月3日）：第一财经报道，腾讯云于7月3日发布通知，DeepSeek-V4 正式版"原厂直供"模型计划于7月中旬在大模型服务平台 TokenHub 和智能体开发平台正式上线。TokenHub 模型列表已显示 DeepSeek-V4-Flash 和 DeepSeek-V4-Pro 的"原厂直供"版本（deepseek-v4-flash-202605 和 deepseek-v4-pro-202606），均支持 1M 上下文、深度思考、Function Calling 和 Cache 缓存。腾讯云成为 DeepSeek V4 正式版的首个第三方"原厂直供"分发平台，将跟随原厂同步引入峰谷定价机制。

02头条美团内部全面限用豆包大模型，强推自研 LongCat 体系

（7月2日）：新浪财经、东方财富等多家媒体报道，美团内部下发通知，限制所有业务团队使用字节跳动旗下豆包大模型。要求自查并规划迁移至 LongCat、DeepSeek 等模型；无法迁移的需提交原因和必要性说明，走单独审批流程。此前美团已于4月限制使用阿里云 Qwen 模型。结合6月30日 LongCat-2.0 的发布，美团正加速向自研 AI 方案倾斜，大模型竞争从"技术较量"延伸到"生态站队"。

03Kimi头条Kimi K3 确认本月发布，参数规模达 2.5 万亿

（7月2日）：月之暗面新一代旗舰大模型 Kimi K3 正式确认将于本月内发布，预计参数规模达 2.5 万亿，将刷新国内大模型参数纪录。K3 将在上下文理解、复杂任务处理、多模态融合等方面实现全方位突破。这是继 DeepSeek V4 正式版之后，7 月最受关注的国产大模型发布事件。

04头条美团 LongCat-2.0 正式发布——首款国产算力全流程万亿参数模型

（6月30日）：美团发布新一代基础大模型 LongCat-2.0，MoE 架构，总参数 1.6 万亿，激活参数约 480 亿，原生支持 1M 超长上下文。业界首个在五万卡国产算力集群上完成训练+推理全流程的万亿参数模型。深度适配 Claude Code、OpenClaw、Hermes 等主流 Harness，测试版本位列 OpenRouter 全球总调用量前三。

05DeepSeek头条DeepSeek V4 正式版官宣 7 月中旬上线，引入峰谷定价机制

（6月29日）：DeepSeek 团队宣布 V4 正式版将于 7 月中旬发布，基于 4 月 24 日上线的预览版升级，支持百万字超长上下文，在 Agent 能力、世界知识和推理性能方面达国内及开源领域领先水平。同步引入 API 峰谷定价机制：每日 9-12 时、14-18 时为高峰时段，价格为平日 2 倍，成为大模型行业首个"分时定价"案例。

06Kimi头条Kimi 新一轮融资启动，估值涨至 315 亿美元

（6月30日）：月之暗面上一轮 200 亿美元估值融资完成交割，新一轮融资已启动，投前估值涨至 315 亿美元。ARR 突破 3 亿美元（3月破1亿、5月破2亿、6月中旬破3亿），API 收入占整体收入 7 成以上。海外付费用户增长 400%，API 收入增长 400%。

趋势洞察5 条

01. 大模型竞争从"技术较量"进入"生态站队"新阶段

美团全面限用豆包大模型，推自研 LongCat 体系，标志着大模型竞争从单纯的技术能力比拼进入"生态站队"新阶段。互联网平台型企业（美团、字节、阿里、腾讯）正在将大模型选型与业务战略深度绑定，构建自有 AI 基础设施。这种趋势可能导致大模型市场的"碎片化"——各家平台优先使用自研模型，第三方 MaaS 平台的"公共性"价值凸显。

02. MaaS 平台分化为"自建+聚合"两条路径

腾讯云 TokenHub 正在走"超级聚合平台"路线，聚合 DeepSeek、GLM、Kimi、MiniMax、Qwen 等多厂商模型，同时兼容 OpenAI 和 Anthropic 两种协议；而阿里云百炼则在"去第三方化"，集中下架 GLM/Kimi/DeepSeek 旧模型，推动用户向 Qwen 系列集中。两条路径代表了不同的平台战略——"开放聚合" vs "自研优先"。

03. DeepSeek 成为各大平台的"公共底座"

美团限用豆包后迁移至 LongCat 和 DeepSeek；腾讯云 TokenHub 引入 DeepSeek V4 原厂直供；硅基流动、百度千帆均上架 DeepSeek 系列；阿里云百炼虽下架旧版但仍保留 DeepSeek-V4-Pro。DeepSeek 正在成为各家自研模型之外的"公共底座"，其开源策略和定价创新（峰谷定价）持续引领行业。

04. 7 月中旬成为"超级发布周"

DeepSeek V4 正式版（含腾讯云原厂直供）、Kimi K3、Seedance 2.5、百度千帆 Token Plan 个人版、GPT-5.6 更广泛开放——五大重磅产品齐聚 7 月中旬。加上美团 LongCat-2.0 已于 6 月 30 日抢先发布并上架硅基流动，7 月中旬将成为 2026 年下半年大模型竞争的决定性时刻。

05. API 定价进入"精细化运营"新阶段

DeepSeek 峰谷定价引发行业热议，标志着大模型 API 定价从"单纯降价抢量"进入"精细化运营"阶段。通过价格杠杆调节资源负载，既保障服务稳定性，又提升商业回报。这是大模型从"烧钱抢市场"向"可持续经营"转变的重要信号。预计更多平台将跟进差异化定价策略。
