01Kimi头条跟进Kimi K3 开源后生态快速扩展——Formula Tools API正式上线，HuggingFace登顶，昇腾Day0适配

7月27日K3完整权重开源后，生态进展迅速：①7月30日，Kimi开放平台如期上线官方Formula Tools API调用通道，支持联网搜索等官方工具通过标准function tool协议集成到开发者应用中，目前限时免费；②K3发布后立即登顶HuggingFace本周热门模型榜；③华为昇腾CANN迅速宣布完成K3在昇腾Atlas A3上的Day0推理适配（基于SGLang推理引擎）；④北美AI基础设施创企OsmanticAI创始人发布KDA高性能算子，在英伟达H20上prefill速度相比flash-linear-attention基线提升1.72-2.22倍；⑤Kimi Code更新支持K3模型，新增子Agent后台任务、Plan模式、Skill调用与嵌套Agent等能力。K3正从"模型发布"阶段进入"生态落地"阶段。

02MiniMax头条跟进MiniMax 8月6日有望纳入港股通——美银证券维持"买入"评级，目标价500港元

MiniMax上市半年禁售期已于7月8日届满。美银证券维持"买入"评级，目标价500港元。关键信息：①MiniMax因同股不同权架构，需满足市值与成交额条件后有望于8月6日获纳入港股通；②管理层在投资者会议上表示，2026年4月ARR已达4亿美元，对年底前实现至少10亿美元ARR有信心；③收入结构出现明显转变，企业及云端API贡献占比显著提升；④M3模型为原生多模态系统，参数规模4,280亿，在多模态任务及前端设计表现突出。若成功纳入港股通，有望吸引南向增量资金。

03DeepSeek头条新增DeepSeek V4三模态版本界面曝光——快速/专家/视觉三档模式引发关注

社区发现DeepSeek在灰度测试中展示了全新三选项界面——"快速"、"专家"及"视觉"，相比当前仅有"深度思考"和"智能搜索"两个选项有显著变化。这意味着DeepSeek未来的新模型可能推出三个版本：快速版（轻量推理）、专家版（深度推理）和视觉版（多模态理解）。此前4月份已有灰度测试发现该界面，但至今尚未正式上线。结合V4正式版已支持原生多模态（图像推理），视觉版可能作为独立模型推出。不过截至7月31日，DeepSeek官方未对此做出正式公告。

04智谱关注跟进智谱GLM-5.5进入8月发布窗口——社区预期持续升温

随着8月临近，GLM-5.5的发布预期持续升温。综合各方信息：①总参数可能突破1万亿（从GLM-5.2的744B大幅跃升）；②上下文窗口预计维持百万级Token；③将延续MIT开放权重路线；④重点强化长周期编码代理能力；⑤也可能采用约1.6万亿参数规模（结合智谱过往采用DeepSeek开源基座的经验）。截至7月31日，智谱官方尚未发布GLM-5.5的模型卡、基准测试或API端点。

05阿里百炼关注跟进阿里百炼Qwen3.8-Max正式版与开源权重即将发布

Qwen3.8-Max-Preview预览版自7月19日上线以来运行稳定，官方承诺正式版将开放完整模型权重开源。社区最强烈的信号是期待能在普通硬件上运行的27B或35B蒸馏版本。目前预览版已覆盖百炼Token Plan、Qoder编码平台、QoderWork办公平台及千问PC/Web端四大入口。正式版发布时间尚未明确，但预计在近期。

06关注跟进腾讯TokenHub等待DeepSeek V4原厂直供上线

腾讯云7月3日公告称DeepSeek-V4正式版"原厂直供"模型计划于7月中旬在TokenHub上线，但截至7月31日，尚未有正式上线的公告。TokenHub模型列表当前仍以Kimi K3为最新上架模型。V4-Pro和V4-Flash原厂直供版本预计将同步引入峰谷定价机制。

趋势洞察4 条

01. K3开源进入"生态变现"阶段

Kimi K3于7月27日开源后，短短四天内生态进展显著：HuggingFace登顶、昇腾Day0适配、KDA算子被第三方优化、Kimi Code开发工具链更新。这标志着K3已从"模型发布"阶段进入"生态落地"阶段。月之暗面的策略清晰——通过开源权重吸引开发者，通过Formula Tools API和Kimi Code等工具链锁定开发者体验，最终转化为API收入和订阅收入。K3在BrowseComp基准上单次任务成本仅为GPT-5.6 Sol的一半、Fable 5的近十分之一，这种"前沿性能+极致性价比"组合正在改变开发者对开源模型的认知。

02. 8月将成为国产大模型又一密集发布窗口

多个重磅产品集中在未来1-2个月发布：GLM-5.5（智谱，8月）、H3（MiniMax，即将）、M3 Pro（MiniMax，9-10月）、豆包AI手机（火山方舟，7-8月）、Qwen3.8-Max正式版+开源权重（阿里百炼，近期）、百度千帆8月12日/14日更新节点。加上DeepSeek V4三模态版本可能发布，下半年国产大模型竞争将更加激烈。

03. MaaS平台进入"ARR/毛利率"验证期

MiniMax管理层确认4月ARR已达4亿美元，年底目标10亿美元；智谱ARR冲击10亿美元；DeepSeek API峰谷定价已全面生效。这些信号表明，大模型行业正从"烧钱换规模"进入"收入验证"阶段。MiniMax企业及云端API收入占比显著提升、智谱三次提价后调用量反增400%——头部平台正在证明"调用量增长的同时可以保住利润"。MiniMax若8月6日成功纳入港股通，将进一步增强资本市场对国产大模型商业化的信心。

04. DeepSeek三模态策略若落地将重塑竞争格局

DeepSeek灰度测试中曝光的"快速/专家/视觉"三档模式，意味着DeepSeek可能将推出独立的视觉版模型。这将补齐V4正式版在多模态上的最后一块拼图（当前V4正式版已支持原生图像推理，但视觉版可能作为独立模型强化该能力）。如果三模态版本正式发布，DeepSeek将同时拥有轻量推理（快速）、深度推理（专家）和多模态理解（视觉）三条产品线，直接对标OpenAI的多模型矩阵策略。
