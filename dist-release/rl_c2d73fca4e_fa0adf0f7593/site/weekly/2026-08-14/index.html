01DeepSeek头条新增DeepSeek V4-Pro 正式版转正 + Harness 开发者预览版公测 + API 全面调价——8月13日"三连发"震动行业

8月13日深夜，DeepSeek 连放三记重拳：

① V4-Pro 正式版上线：模型版本更新为 DeepSeek-V4-Pro-0813，总参数1.6万亿（MoE），每token激活490亿参数，100万token上下文窗口，最高38.4万token输出。支持思考/非思考双模式，原生支持JSON结构化输出、Tool Calls、Responses API和Anthropic API。官方自测相对预览版大幅提升——DeepSWE从12.8飙至62.7（暴涨近5倍，超越Claude Opus 4.8），TerminalBench 2.1从72.1升至87.9，DSBench-Hard从约33.6翻倍至67.2，Cybergym 83.3超越Claude Fable 5。

② DeepSeek Harness（DSH）开发者预览版v0.1正式公测，同步MIT开源：GitHub仓库半小时星数破万，截至发稿已达40k+。核心设计理念："一切皆插件（Everything is a Plugin）"，可替换范围从模型适配器、工具、技能一直延伸到Agent Loop、沙箱、会话管理和UI。底层基于Cordis插件系统，支持动态插件运行时（模型可自己写插件并安装）。提供四种运行模式：标准模式、PTC模式（程序化工具调用）、极简模式、创造模式。内置基于Linux Landlock的landlock-run沙箱，100+个插件，221+个npm包。快速启动：npx @deepseek-ai/dsh web。

③ API全面调价——峰谷定价8月17日0时生效：V4-Pro高峰时段输出价格上涨约350%，最低涨幅也有50%。高峰时段为工作日9:00-12:00和14:00-18:00，空闲时段价格为高峰的一半。这是DeepSeek成立以来幅度最大的一次调价。（跟进报道涨价预告：2026-08-11）

公式：模型（大脑）+ Harness（身体）= 智能体（Agent）。DeepSeek从"模型提供商"正式进入"Agent平台"赛道，直接对标Claude Code和OpenAI Codex。

02头条新增阿里千问Qwen3.8-Max权重正式开源——2.4万亿参数旗舰模型HuggingFace/ModelScope同步发布，UnslothAI量化方案降至397GB

8月13日，阿里千问团队正式开放Qwen3.8-2.4T-A95B模型权重。这是千问历史上首次把Max级别旗舰大模型对外开放。关键信息：①模型已在魔搭社区、HuggingFace同步发布，Qwen3.8-27B轻量版预告后续开放；②原始权重体积4.9TB，UnslothAI推出动态1-bit分层选择性量化方案，压缩至397GB（缩减91%），只要设备内存+显存超410GB即可本地运行；③模型原生支持262K上下文，拓展最高101万Token，内置视觉输入和工具调用能力；④全系默认开启思考模式，无法关闭；⑤基准成绩亮眼：PaperBench 93.0超越GPT-5.6 Sol和Fable 5，OSWorld-Verified 86.1排名第一，但SWE-benchPro和TerminalBench2.1略低于GPT-5.6 Sol和Fable 5。（跟进报道Qwen3.8-Max开源窗口：2026-08-11/08-07/08-04）

趋势洞察5 条

01. 8月13日成为2026年下半年大模型行业"超级日"——DeepSeek+阿里同日引爆

8月13日同时发生两件具有行业里程碑意义的事件：①DeepSeek发布V4-Pro正式版+Harness公测+API调价"三连发"；②阿里正式开源Qwen3.8-Max 2.4万亿参数旗舰权重。加上百度千帆8月12日/14日两个更新节点执行、腾讯TokenHub上线V4原厂直供、智谱GLM-5.3发布在即，8月中旬已成为2026年下半年最密集的大模型发布窗口。这一天可能被回顾为国产大模型从"模型竞争"全面转向"Agent平台竞争"的转折点。

02. DeepSeek Harness定义Agent平台新范式——"一切皆插件"挑战Claude Code

DeepSeek Harness的"一切皆插件"设计理念把可替换范围从工具层扩展到整个运行时——模型、Agent Loop、沙箱、会话管理、UI均可替换，甚至模型可以在运行中自己写插件并安装。这比Claude Code和Codex的可扩展性更深一层。MIT开源+GitHub 40k星+221+个npm包+100+个插件，DeepSeek正在构建一个Agent平台生态，而不仅仅是一个编程工具。公式"模型+Harness=Agent"精确定义了这一新赛道。1Panel等运维面板已第一时间上架，生态扩展速度超预期。

03. API定价格局重构——DeepSeek从"价格屠夫"转向"价值定价"，行业迎来涨价潮

DeepSeek V4-Pro正式版峰谷定价后，高峰时段输出价格上涨约350%，最低涨幅也有50%。这标志着DeepSeek从"价格屠夫"战略转向"价值定价"——V4-Pro正式版的DeepSWE 62.7、Cybergym 83.3等成绩已超越Claude Opus 4.8和Fable 5，DeepSeek对产品力有充分信心。此前V4-Flash输入1元/输出2元的极低定价曾是行业标杆，涨价后将为智谱GLM-5.3等竞品释放定价空间。行业正从"价格战"全面转向"价值战"和"Agent平台战"。

04. 开源权重进入"2万亿级标配"时代——一周内Qwen3.8-Max和DeepSeek Harness双重引爆
