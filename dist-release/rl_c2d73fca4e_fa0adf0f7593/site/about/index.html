关于

MaaS Daily 是一个追踪全球主流 MaaS（Model as a Service）平台动态的每日报告站点。

覆盖范围

  • 国内平台（9）：火山方舟、阿里百炼、百度千帆、腾讯混元、硅基流动、智谱AI、Kimi、MiniMax、DeepSeek
  • 海外平台（6）：OpenAI、Anthropic、Google Gemini API、Google Vertex AI、Mistral、Cohere、xAI
  • 行业源（3）：HuggingFace、Artificial Analysis、LMArena

追踪维度

每个平台覆盖以下 6 个维度：

  • 模型列表（P0）
  • API 定价（P0）
  • 更新日志 / 发布公告（P0）
  • API 参考文档（P1）
  • 官方 GitHub 仓库（P1）
  • 官方博客 / 新闻（P1）

更新频率

每周二、周五各一期追踪报告，覆盖上一周期的模型发布、定价变更、API 更新与开源动态。
