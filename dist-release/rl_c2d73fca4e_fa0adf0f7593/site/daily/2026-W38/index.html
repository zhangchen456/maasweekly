新模型上架与旧版清理并行周

01

密集发布：新模型集中上架与评测

本周阿里百炼上架 DeepSeek V4.1 Flash，并公布闲时定价 1.094 元；xAI 同步上调 Agent 起始价至 $0.08/min。Artificial Analysis 新增 K2 Horizon 0.9B/3.7B/7B/MoVA 36B A4B 评测，LMArena 则新增 claude-fable-5.1-max 多个 Elo 分数（1498/1513/1710）。多平台同日更新，显示新模型发布节奏加快。

02

下线与清理：旧版模型及评测条目移除

阿里百炼移除 deepseek-v4-flash-0731，替换为 deepseek-v4.1-flash；Artificial Analysis 移除 Gemini 3.8 Flash 评测条目；LMArena 替换 claude-fable-5 及 opus-4-6 旧分数；Cohere 删除旧博客『Automating fork maintenance with AI agents』。各平台同步清理旧资源，为新内容腾出空间。

03

价格锚点：闲时定价与 Agent 调价

DeepSeek V4.1 Flash 闲时定价 1.094 元，成为本周价格锚点；xAI Agent 起始价从 $0.05/min 上调至 $0.08/min，涨幅 60%。两者均属增量调整，未引发连锁反应，但显示平台在成本与需求间寻求平衡。
