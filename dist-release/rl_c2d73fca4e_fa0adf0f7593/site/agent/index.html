验证问题

安装成功的标准是完成一次真实查询（拿到数据版本、数据截至时间、覆盖范围与永久链接），不是文件下载或配置保存。在新会话中问：

  1. 「用 maas-daily 查最近几天 OpenAI 有什么变化」——回答应引用数据版本与覆盖日期
  2. 「查 gpt-6-astra 的输入价格，给出条件与证据 ID」——应含币种、单位、适用条件、观察时间
  3. 「最新一期周报讲了什么」——应为正式周报（日期型 ID），不是滚动摘要

配置 MCP 或安装 Skill 后可能需要开启新会话才能发现工具。
