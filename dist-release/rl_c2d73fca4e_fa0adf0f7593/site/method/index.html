我们如何观察 MaaS 平台

截至 2026-09-16，本数据集覆盖 2026-09-04 至 2026-09-16共 3181 条变化记录、1335 条价格事实、6285 条证据、23 期正式周报。以下是这些数字的产生方法与边界。

1. 观察，不是转述

每日定时抓取各平台官方页面（模型列表/定价/更新日志/博客），与上一次快照逐行对比。这是页面文本的观察：受截断、页面抖动与重算影响，存在噪声边界。来源页变化不等于供应商正式发布、下线或调价——那需要官方公告佐证。

2. 五种时间，各是各的

  • 首次观察时间（observedAt）：我们的抓取程序看到该内容的时间；
  • 来源发布时间（publishedAt）：供应商官方声明的时间（无来源则为空，不用观察时间顶替）；
  • 价格事实观察范围：该价格成立的观察区间（版本链）；
  • 数据截至（dataThrough）：本数据集的覆盖上限——当前为 2026-09-16；
  • 站点构建时间：网页发布时刻，与数据时间无关。

首页与价格页显示各自的数据时间，不用构建时间冒充。

3. 证据的完整性分层

每条价格事实附证据（当时保存的页面摘录 + 定位方式 + 摘录哈希）。完整性分三档：complete（模型/金额/单位可在摘录内复核）、partial（形态完整但某要素不在摘录内——如实披露，不因存在就算已验证）、unavailable（历史数据无证据可回溯）。摘要、定位、官方来源各自能证明的内容不同——逐层看，不跳层。

4. LLM 摘要可能出错

部分变化摘录由 LLM 生成（标记 summaryOrigin=llm），可能出错。核验路径：稳定 ID → 结构化事实 → 证据摘录 → 官方页面，逐层可查。RSS 与 API 中的 LLM 摘要均带披露标记。

5. 价格的条件完整性

每条价格保留原币种（USD/CNY）、单位（如 /1M token）、计费组件（输入/输出/缓存读/缓存写）、区域、档位、计费模式与附加条件（长上下文阶梯、峰谷时段）。不做跨单位、跨条件的自动「最低价」结论——多候选逐项列出，由你按适用条件判断。

6. 衍生数据的边界

榜单（如 OpenRouter 调用量）来自第三方，汇率与部分能力榜为人工维护——各自标注更新时间；未知值显示未知，不补数字。

7. 三种健康信号

  • 抓取成功：页面下载与解析完成；
  • 价格解析通过：门禁校验（金额/证据链/身份）通过；
  • 最后有效事实时间：该来源最近一次产出被接受的事实。

三者不同。失败沿用旧数据时状态标 stale（附最后成功时间），不显示为新数据；partial/unknown/unavailable 各按字面理解。

8. 修订、撤回与缓存

记录可修订（修订链保留历史）与撤回（详情页仍可访问并标注）。RSS 是静态投影：修订保持条目身份，但已缓存的撤回内容无法可靠召回——详情页与 API 是最新状态的权威来源。接口变更见 变更记录。
