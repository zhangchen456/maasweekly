# T08 付费状态与权益合同（候选，2026-10-04）

真实渠道与沙箱账号未确定。既有 US$9.90/月为计划价；模拟器使用 USD 990 最小单位/月，不代表收费批准。禁用 live、真实扣款与真实退款。供应商托管结账，本站不接收卡号。

| 事实/动作 | 付费状态和权益 |
| --- | --- |
| 首次付款/续费成功 | 仅服务端核验供应商成功且金额、币种、订单/用户/订阅一致后追加支付事实及周期权益；浏览器返回不授予权益 |
| 续费失败 | 不新增周期；已付周期保留至到期，无额外宽限 |
| 周期结束取消 | 停止续费，已付周期保留；取消不退款 |
| 立即终止 | 终止 paid 访问并停止续费，不隐式退款 |
| 到期 | 当前时间达到周期结束即无该 paid 权益，服务端每次判定 |
| 部分退款 | 供应商最终成功后记账；对应周期权益保留 |
| 全额退款（累计） | 供应商最终成功后撤销对应订单的周期；其他成功周期不受影响 |
| 争议/拒付 | 争议期间暂停对应付费订阅；胜诉恢复剩余已付周期，败诉撤销对应周期；不伪造退款 |

独立来源 priority：有效 paid > 有效 beta > 有效 manual，保留已交付 T02 的免费来源顺序；手工 revoked 保持对 beta 的禁止，但不撤销 paid。退款/争议/终止只作用于 paid，不撤销独立 manual/beta；因此仍可能拥有 Plus。不得自动把 beta 转 paid，不自动开启专业邮件。

金额为非负安全整数最小单位，currency 为独立币种。不同币种不求和。订单金额冻结，不编辑金额，不补造凭证。支付、退款、财务变化追加不可变事实；状态为可重建投影。保存供应商对象 ID。订单不是到账金额；收入、退款、手续费、结算各自展示，缺供应商结算为 unknown。

Webhook 原始字节验签、时间窗校验、供应商事件 ID+内容 hash 去重，冲突拒绝；接收事实与处理尝试独立追加，失败保留可恢复。重复/乱序以供应商对象核验与唯一支付事实控制，失败事件不能覆盖成功事实。漏回调通过同一核验入口补查。退款先持久化请求/可退余额预留再调用供应商，提交不等于成功；未知不自动重发，使用稳定供应商幂等键查询恢复。

对账按 currency、[from,to) 及来源比较成功支付/成功退款、供应商账目；费用与结算未知不能显示零。差异追加 source/object/observed/expected 和处理记录，不修改原账目。

此合同需要渠道、币种/价格/周期、生效规则确认；模拟场景通过不等于真实供应商沙箱验收。
