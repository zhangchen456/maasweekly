2026-10-02 已上线；CI 54 组全量回归、四入口核验和线上 5 个浏览器场景全部通过。实际版本、日志与截图见 `release.md`。

## 交付范围

首页共用一个价格表，通过“旗舰能力 / 主力性价比 / 编程专项”三个 Tab 切换，分别展示 8 / 8 / 2 个型号。默认旗舰组；切换保留人民币/美元与自定义汇率。支持方向键、Home、End；未启用 JavaScript 时仍能查看全部 18 行。英文首页同步为单表 Tab，保留原币种报价。

18 个型号均有可核验的输入与输出价格，并可查看同一档位的缓存读取、区域、上下文、时段、观察日期及完整证据。没有用旧型号报价或在前端硬填金额。

## 数据修正

- OpenAI：区分 standard / batch / flex / fast / ultrafast，区分 ≤272K 与 >272K；证据保留表外百万 token 单位及官方上下文提示。
- Anthropic：支持两层表头与表体分组标题，模型名从官方链接提取，补入 Opus 5.5 和 Sonnet 5.5；保留 5m/1h 缓存写入条件。
- Google：补入 Gemini 3.1 Pro Preview；解析 200K 上下文阶梯，缓存读取与按小时存储分开；优惠价根据原始快照观察日期选择，保留截止日期。
- Kimi：按列名解析 K3 的八列价格表，修正缓存写入列导致的输入/输出错位；保留 K2 编程与高速型号各自报价。
- DeepSeek：移除 API 名的脚注标记，收录当前 `deepseek-flash`，核验 V4 Pro 新价，并按官方 UTC 峰谷时间记录。
- 豆包：常规、低延迟、低优与批量分别记录，首页使用常规实时档，避免误展示低优价格。
- 百炼：从当前官方定价页补入 Qwen3.8 Max 稳定身份；智谱沿用本次成功采集的官方报价。

首页选价优先使用该型号最新一轮观察结果，然后选择明确的区域、实时标准档、低上下文与高峰档。旧解析留下的历史身份不会覆盖本轮的适用条件；本轮证据不完整时不会回退冒充可核验报价。
