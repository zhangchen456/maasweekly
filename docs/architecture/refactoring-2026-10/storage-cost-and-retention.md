原始快照 248,330,316 bytes，内容寻址后 247,229,743 bytes；仅减少 0.44% 重复内容。把已迁移 raw 从未来 checkout 移除，理论可少取回 236.83 MiB；按本次 manifest 元数据 1.65 MiB 估算，净额约 235.17 MiB。该收益在隔离的代码/元数据包中演练，主仓库未 git rm，历史 pack 未缩小。

最近 14 个已存观察日（2026-09-18–2026-10-01）平均新增日目录 raw 9.14 MiB。若频率、来源和响应大小不变，30 个观察日约 0.268 GiB。这个样本描述已存文件，不是 Git 压缩增量；AR-04 后原始 CAS 与旧日槽位可能并存，增加采集频率也会改变增长。不能给出可靠的耗尽日期。

最终本地演练：冷对象复制 2.974s；固定代码/元数据包恢复 24.554s，96,561 个文件、595,847,852 bytes；raw 恢复含中断续接 4.453s，payload cache 64,884,498 bytes ≤64MiB。旧缓存逐次扫描的对照为 50.006s；优化后复用索引，全部字节与公开版本仍一致。

本地价格归档验证、公开导出与完整 site build 分别约 24.638s, 17.585s, 53.720s。上述分段时间不包括依赖缓存复制、所有工具开销或远端传输。生产 RTO/RAM 预算尚未设定，因此本项完成恢复实测，不宣称生产恢复预算达标。

每次空恢复的远端最低预算应同时包含：

- 原始对象 GET：2,188 个，0.230 GiB；对象遍历/校验也是请求与 CPU 成本。
- 代码/元数据：本次 0.555 GiB，包含事实、修订和公开保留版本；大量小文件的展开成本不可省略。
- npm/运行依赖：本次来自已有锁定缓存，冷下载需另测。
- 每月总成本 = 平均存储GiB×存储单价 + 新对象PUT次数×PUT单价 + 缓存miss的GET次数×GET单价 + 取回/部署流量GiB×出网单价 + 备份/请求附加费。
- 最低传输时间 = bytes/有效吞吐；小对象还增加 请求数×往返延迟/有效并发，需计入重试和恢复校验。

API 保持从自足的 immutable 本地包读取，GET 成本不与访客请求数直接绑定。每个构建的缓存独占且有 payload 上限，缓存淘汰不删除 store。raw 全量迁移清单覆盖现存历史，但不会修复缺失历史：199 个快照元数据中 26 个 hash 无原始字节匹配，关联 1,333 份摘录证据仍保持原记录。该缺口在迁移前已经存在，不能把它们报告为 raw 已恢复。

结论：本地适配器/幂等复制/中断恢复/故障隔离可以交付；远端启用、writer 引用切换、停止 Git 冗余和真实清理为 DEFERRED。raw 超过 1GiB、采集频率明显增加、clone/CI/恢复超出认可预算时重新评估；这些是复查建议，不是自动删除规则。公开保留版本与大量事实修订仍是重要成本，AR-08 综合实际容量决定后续优化，不因对象迁移先引入数据库或队列。
