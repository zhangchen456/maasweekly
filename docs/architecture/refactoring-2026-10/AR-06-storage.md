# AR-06：存储分层与历史迁移

状态：LOCAL_VERIFIED（本地适配器与迁移演练）；远端启用及 Git 移除为 DEFERRED，按用户确认不启用远端。优先级：P2。依赖：AR-03、AR-05；容量预算参考 AR-01/08。

## 目标与边界

减少 Git 中持续增长的原始快照和重复历史产物，让代码 checkout、备份和发布的成本可控。当前与保留期内公开版本仍须可完整验证和离线服务。

本任务分为“清单与方案”“迁移演练”“启用与清理”三个阶段。对象存储账号、预算或路径尚未确定时，可以交付前两阶段的本地适配器与演练结果，但不得把正式迁移标为完成。

交付：存储分类表、迁移清单、复制/校验/恢复脚本、构建取回流程、恢复实测及 `AR-06-result.md`。

## 6A. 清单与选型

盘点 `data/snapshots`、`data/price-*`、records/revisions、`data/public/v1/releases`、站点派生产物和 `dist-release`。每类记录文件数、实际字节、增量、引用者、保留要求与重建成本。

区分三种保留：证据/事实历史保留、公开 cursor 版本保留、可部署 release 保留。三者不是同一个清理周期；公开数据 7 日规则不意味着原始证据只需保留 7 日。

先选原始大快照与可重建重复包作为迁移候选。记录对象存储方案的区域、认证方式、月容量/读取预算、故障时恢复路径与责任；账户和计费选择需要实际配置输入，不能自行猜测。没有选定远端时使用本地 filesystem adapter 完成演练。

## 6B. Blob 接口与元数据

定义小型接口：`putIfAbsent(hash, bytes)`、`get(hash)`、`verify(hash)`。对象按内容 hash 寻址，上传已有同 hash 内容幂等，读取必须校验 hash/bytes。业务层引用逻辑 blob ID，不散落桶域名或本地绝对路径。

给现有 snapshot 内容标识建立可追溯映射；locator、evidence ID、fact version ID 不因存储位置改变。元信息包含 content hash、bytes、contentType、来源快照引用；凭据与私有存储地址不进入公开 API。

历史归档读取器先走兼容层，可读取旧文件与新 blob；缓存目录必须有容量上限和明确清理规则。

## 6C. 复制、对账与演练

1. 从固定 commit/输入版本生成只读迁移清单，记录源相对路径、目标 hash、bytes、引用关系。
2. 复制到目标，重试幂等，逐对象校验。失败清单可以单独续跑，不能因部分上传成功就切换全部引用。
3. 在空目录模拟新环境，仅凭代码、元数据与目标存储恢复必要输入，执行归档校验、公开导出及站点构建。
4. 对比迁移前后公开集合、datasetVersion、证据链接与价格事件，解释全部差异。
5. 模拟对象缺失、hash 不符、存储不可达、部分上传、恢复中断。候选构建失败不得影响在线 last-known-good release。

保持在线 API 使用本地完整 release；对象存储故障不应转化成每个查询请求的远端依赖。构建时按 manifest 取回所需对象并完整验证，再组装自足的服务产物。

## 6D. 启用、保留与清理

先启用兼容读取，再启用新数据写入目标，观察并验证后才从 Git 跟踪中移除已迁移的大文件。`git rm --cached` 只减少后续 checkout 内容，不会缩小已有 Git 历史，结果必须如实说明。

不在本任务重写 Git 历史。若未来确需清理历史，另立任务处理克隆、分支、回滚引用和备份协调。

清理采用 manifest 引用的标记与扫描：先列出候选和所有引用者，只清理无引用且超过明确宽限期的对象。应同时考虑现行事实、修订链、公开保留版本与可回滚 release，不能只看 current。

迁移后第一次清理前，必须已有恢复成功记录与可审查的清理清单。存储迁移、引用切换、停止本地冗余、清理分别记录，不合并成一个不可分解脚本。

## 验收标准

- [x] 每个迁移对象的 bytes/hash 与引用均通过对账，无悬空证据。
- [x] 空目录恢复完成，分阶段耗时与传输量记录。生产恢复预算尚未设定，是否达标待上线环境确认。
- [x] 同输入迁移前后公开数据版本、ID、永久链接与查询结果一致。
- [x] 缺对象/存储不可达使候选构建明确失败，在线站点和 API 继续使用旧 release。
- [x] 公开历史 cursor 在合同保留期内仍可读取，回滚 release 可独立启动。
- [x] Git 新 checkout 和未来日增量的收益有测量；没有宣称已缩小未改写的历史。
- [x] 清理 dry-run 只列出无引用对象，故障恢复和中断续跑有验证。

验收证据和历史原始文件缺失说明见 [AR-06-result.md](./AR-06-result.md)。以上勾选仅代表已授权的本地范围。

## 决策与回退

完成评估后，若成本/复杂度超过收益，可用 `DEFERRED` 交付，记录本地增长趋势、触发阈值和复查条件。这样完成的是评估，不是存储迁移。

正式切换后回退优先恢复兼容读取或从目标恢复旧路径，保留迁移对象直到所有保留版本与回退窗口结束。不能假设回滚代码就能恢复已经删除的历史文件。
