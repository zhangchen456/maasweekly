# 邮箱注册与密码登录

新用户在登录窗口选择「注册账号」，邮箱验证码验证成功后创建原有个人账户，并设置、确认密码。之后默认使用邮箱和密码登录，登录状态保留30天。

已有验证码账户通过「忘记密码 / 老账号设置密码」验证原邮箱并设置密码，账号ID、套餐、关注、个人资料和保存的偏好不变。账户中心也提供「设置 / 重置密码」入口。

私有接口沿用本站 Origin、Cookie 和 no-store 保护：

- `POST /api/account/request-code`、`verify`：验证邮箱并创建或恢复账户，会话拥有10分钟的一次性密码设置权限。
- `POST /api/account/password`：设置8至128字符密码；仅接受刚验证邮箱的会话，消费设置权限并撤销其他会话。
- `POST /api/account/login`：邮箱与密码登录，邮件服务不可用时仍可登录。
- `GET /api/account/me`：新增 `user.hasPassword`，不返回密码哈希。

数据库自动新增 `passwords`、`password_attempts`、`email_proofs` 表，不修改原有用户行。密码通过 Node.js异步scrypt和随机盐保存；登录错误统一返回邮箱或密码错误，邮箱15分钟内限制10次尝试，同时保留请求来源限流。

验证：后端账号测试12项、前端登录交互测试2项；API TypeScript构建与Astro站点构建。新增测试涵盖旧账号迁移、密码存储、错误尝试限制、密码重置、会话撤销、服务重启、无邮件密码登录以及注册分步交互。
