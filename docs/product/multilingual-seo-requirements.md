# MaaS Daily 中英文版本与默认语言需求

日期：2026-10-01。状态：需求交接，尚未实现。网站：https://daily.maas.click。

## 目标与范围

为英文用户提供可独立阅读、可被搜索引擎抓取的模型价格查询入口。首次从网站首页进入时，中国大陆 IP 默认中文，其他国家或地区 IP 默认英文；支持页面按钮切换并记住选择。语言版本共享同一份可靠数据，不改变模型身份、价格事实或公开接口。

本文件是下一 session 的实现输入。本 session 只整理需求，不修改站点或发布。执行者开始前应重新读取当前项目规则、生产状态、合同和发布要求，不把历史记录当作当前事实。

## 第一阶段交付页面

| 内容 | 中文地址 | 英文地址与要求 |
| --- | --- | --- |
| 首页 | `/` | `/en/`，说明价格追踪价值、重点模型和数据更新时间 |
| 模型目录 | `/models/` | `/en/models/`，包括目录交互和数据状态 |
| 价格查询 | `/pricing/` | `/en/pricing/`，翻译筛选、表格、提示和交互结果 |
| 模型详情 | `/model/{modelId}/` | `/en/model/{modelId}/`，第一批至少覆盖下列五个候选模型 |
| 数据方法说明 | 按现有内容核实，缺少则补建 | 英文完整说明数据来源、更新、计费比较限制和证据 |

首批候选：`deepseek:deepseek-v4-pro`、`alibaba:qwen-plus`、`alibaba:qwen3-coder-plus`、`google:gemini-2.5-pro`、`zhipu:glm-5.2`。实现时核对最新数据；某个候选缺少可靠价格或证据时如实记录并替换，不凑数量。目录和价格页中的模型链接必须有明确去向：有英文详情则进入英文详情，否则明确标注中文页面，不能产生不存在的英文链接。

全量日报、周报、历史变化和证据正文翻译，以及第三种语言、汇率换算、地区价格推断、社区推广不在本期范围。英文首页不机械复制未翻译的中文资讯列表。对已有接入说明提供必要的英文介绍和有效入口，不改变 REST、MCP、RSS、Skill 契约。

## 默认语言与切换规则

“国内”本期定义为中国大陆，国家代码 `CN`；港澳台和其他地区默认英文。IP 只能作为默认值，VPN 或定位误差可由用户手动切换纠正。

语言决策顺序：明确请求的语言版本或显式语言参数 > 已保存的手动选择 > IP 国家 > 定位失败时的回退。显式访问英文 `/en/...` 永远显示英文，直接访问现有中文内容路径永远显示中文，不因 IP 强制改写分享链接或搜索落地页。

IP 自动选择仅应用于无显式语言参数的首页 `/`：首次海外访问转入 `/en/`，首次中国大陆访问留在 `/`。这既满足从网站主入口进入的默认语言需求，也保留中英文页面各自的稳定地址。任意深层中文链接均自动转英文不属于本期要求，因为对应英文页可能尚未存在，并会干扰搜索抓取。

首页接受 `?lang=zh` 和 `?lang=en` 作为显式选择入口；参数不形成额外索引页面，canonical 指向对应无参数语言首页。选择中文后回到 `/`，不得立即被 IP 再次送回英文。必须设计并测试循环防护。

页面提供清晰的 `中文 / English` 链接或按钮，桌面与移动端都可见且可键盘操作。切换优先进入当前内容的对应语言版本，保留语义一致的筛选和锚点；没有译本时进入目标语言首页并说明该内容暂未翻译。菜单中的跨语言入口要标明语言。

手动选择保存 180 天，可使用第一方 Cookie 或等效机制；必须在自动选择执行前读取。自动 IP 选择不覆盖手动偏好。存储不可用时本次切换仍应成功，跨次记忆可降级。直接打开某个语言链接不应擅自永久改写已保存偏好。

## IP 判断与交付约束

先核实当前静态 Astro 产物、反向代理/CDN 和发布链是否已经提供可信国家信息，再选择最小改动实现。静态 HTML 本身不能获知访客 IP，不得仅增加前端语言切换器就宣称完成 IP 默认语言。

优先使用现有可信 CDN/代理的国家信息或服务端 GeoIP；客户端不得伪造国家头影响判断。不要把客户端传入的任意 `X-Forwarded-For` 当作真实 IP。若使用浏览器增强方案，可由站内最小只读入口返回国家代码，然后仅在首页做一次导航；入口设短超时（建议 1 秒），失败不阻塞浏览或重复跳转。不要默认将访客 IP 发送给新的第三方地理服务。

必须记录所选方案、国家信息来源、更新方式、失败行为及其对现有部署的影响。如需新的 CDN 权限、GeoIP 数据许可、代理配置或生产服务，先完成可审查的实现与配置说明，再按实际项目审批要求处理；缺少条件时准确标记 IP 功能未完成。

定位失败：优先已保存选择，否则浏览器首选语言是中文则中文，其余英文；若无法获得浏览器语言，中文。浏览器增强方案无 JavaScript 时首页保持静态中文，英文链接仍可访问，必须如实记录该降级。不能声称所有访问方式都已满足按 IP 自动选择。

如服务端或边缘导航涉及缓存，必须避免某个国家或用户的语言跳转污染其他用户的响应；仅对入口使用临时导航，不使用永久 301 表示 IP 偏好。稳定内容 URL 的响应语言不随 IP 或 Cookie 改变。禁止新增原始 IP、精确位置或完整请求头的埋点采集。

## 英文内容与数据一致性

英文版包括 title、description、H1、导航、正文、按钮、加载状态、空数据、过期数据、错误提示及刷新结果。核心价格和解释必须存在于生成 HTML，关闭 JavaScript 仍可读；不能靠浏览器翻译或进入页面后机器翻译充当英文版。

价格、币种、单位、区域、service tier、billing mode、context band、time condition、时间和证据状态均来自与中文版相同的完整性校验 release。保留原始精确金额，不做隐式汇率换算，不修改 modelId、recordId、公开字段或官方来源链接。原始技术枚举可显示英文解释，但不能丢失可核对的条件。

英文文案面向查询和选型需求，避免无依据的最低价、排名、可用性或流量承诺。海外可注册、支付和调用等信息仅在有可靠官方依据时表述；没有依据则标注未核实，不因有英文页面推断平台支持海外用户。

## SEO 要求

中英文使用独立、稳定且可直接请求的 URL。保留原中文地址。每个版本使用自己的绝对 canonical，不能把英文 canonical 指向中文。使用适当的 HTML lang：中文 `zh-CN`，英文 `en`。

实际存在且内容对应的译本互相提供 `hreflang="zh-CN"` 与 `hreflang="en"`，包含自身，并双向一致。不存在的译本不生成 alternate 链接。`x-default` 如使用，必须指向真实的默认/选择入口并说明其策略，不能随意批量添加。

将有实质内容的英文页面加入现有 sitemap 生成链，继承空数据/noindex、URL 去重和真实更新时间原则；robots 不阻挡英文或必要资源。英文站内链接优先英文路径，无须通过语言检测才能找到 `/en/`。同一个稳定 URL 对普通访问者和搜索引擎提供相同正文，不依靠 User-Agent 特判来隐藏语言版本。

Google 建议独立语言 URL 和显式切换链接，并提醒基于语言/IP 的自动重定向可能妨碍抓取。因此本需求把自动选择限制在无明确语言选择的首页入口，所有具体语言内容始终可直达；IP 功能本身不是 SEO 排名手段。[Google 多语言网站指南](https://developers.google.com/search/docs/specialty/international/managing-multi-regional-sites)

保留首页百度验证标签 `codeva-UXsh2qWgbK` 和 Google DNS 验证配置。验证前后检查百度实际抓取到的首页仍有验证标签；不要假定浏览器看到标签就代表平台验证通过。IP 入口不得影响 robots、sitemap、验证文件、API、RSS、MCP、Skill 或资源请求。

## 统计与效果判断

沿用当前 Umami 和既有事件，避免重复 page_view。英文路径天然作为语言区分；如补充语言切换事件，可采用 `language_switch`，仅记录 from、to、页面类型和 manual 触发方式，不记录原始 IP或把自动导航记为用户切换。更新埋点文档并验证已有事件兼容性。

上线后用 Search Console 观察英文页的索引、查询、国家、展示和点击，结合 Umami 查看模型访问、证据点击及接入配置复制。配置复制不等同实际安装成功。本期记录基线和人工复盘建议，不额外创建自动任务，也不承诺排名或新增流量。

## 验收清单

1. 新访客从 `/` 进入：CN 默认中文，非 CN 默认英文；模拟至少 CN、US、HK，并核对真实国家来源，不能只测试前端伪造值。
2. 海外访客手动选择中文后刷新和再次进入仍中文；国内访客选择英文后同样保持英文。显式英文路径不被国内 IP 改写，显式中文深层路径不被海外 IP 改写。
3. 首页显式语言参数、跨语言切换、无译本回退、参数与锚点处理均有效；无循环、无反复导航、无缓存串语言。
4. 定位超时/错误、存储禁用、JavaScript 禁用按规定降级，不出现阻塞或空白；说明任何首屏闪动和方案限制。
5. 首批页面生成 HTML 有完整英文正文；价格与中文版及源 release 一致。刷新后英文状态和标签保持正确，网络失败或版本不一致时不丢失可靠静态内容。
6. title、description、lang、canonical、双向 hreflang、英文内部链接、sitemap 和 noindex 行为正确，无不存在的语言 URL；关闭 JS 可直达两种语言。
7. 移动端、桌面端和键盘切换可用；原有埋点、中文页面和四个公开接口保持兼容；百度验证标签保留。
8. 完成与改动相称的自动测试、真实浏览器验收及标准发布门禁；线上验证实际响应、国家选择与缓存行为。不可用的账号或检测能力明确列为未验证事项。
