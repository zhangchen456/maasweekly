# 首批待审核样例

6个JSON文件：3篇变化详解、2份条件对照、1份完整公开结构样例。基于2026-10-01至10-03平台归档的官方来源差异编写，不引用模型记忆补充事实。

全部是开发草稿，尚未导入生产或正式出版。统计周未结束，所以标记为partial；覆盖结束精度为日期，不编造精确时间。没有可靠模型归属，首批仅标厂商范围。

发布前核对归档最新修订、证据与正文、正式编辑/审核人。用运营CLI依次导入、审核、出版，公开样例只有明确的sample=true文件。其他全文保存在服务端数据库，不进入静态站。

prepare-samples.mjs用于重建这些草稿，运行时读取本仓库观察记录。开发期间未测量独立编辑工时，也未完成目标用户和付费验证。
