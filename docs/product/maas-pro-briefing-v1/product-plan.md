# MaaS 专业情报简报：产品计划

版本：0.0.1｜状态：待评审｜日期：2026-10-03。

## 1. 产品与目标

MaaS 专业情报简报持续跟踪用户关心的 MaaS 厂商，把重要变化整理成有前后对照、历史关联和来源证据的每周简报。用户可从简报进入详解或专题，并在网站、邮件、Agent/MCP 和私有 RSS 中使用相同内容权益。

首版只推出一个专业订阅产品。核心增量是经过筛选、核验和比较的成果；访问凭证负责识别权益，不能代替内容价值。独立用户访谈和付费意愿尚未验证，角色、需求强度、产能及商业目标均按假设或试点目标记录。

### 1.1 当前基础

账户、真实邮件和跨设备设置已上线验收；模型关注、标准每日提醒、价格/用量对比、个人数据导出已有。公开 REST、MCP、Skill 和 RSS、稳定记录与证据归档可复用。

新增工作：专业内容及审核、专业订阅范围、受保护阅读与导出、权益有效期、外部访问凭证、专业内容接入、内容投递与转化统计。个人资料导出不等于专业报告导出；公开历史记录不等于已制作的专业历史分析。

### 1.2 目标用户

| 用户 | 具体工作 | 期望结果 |
| --- | --- | --- |
| MaaS 产品经理与竞争分析人员（首要） | 持续比较若干厂商产品、定价与服务条件 | 每周获得可用于内部讨论的变化总结及依据 |
| AI 产品技术负责人（首要） | 跟踪正在使用的模型和平台 | 明确哪些调整适用于自己的选择范围，减少遗漏和误读 |
| 行业研究人员（次要） | 回查时间线、组织报告材料 | 有明确覆盖范围的历史与横向对照，可追溯引用 |

首要场景：用户跟踪阿里百炼、火山方舟、硅基流动等指定对象，只关心价格、计费条件和模型生命周期，每周需要一次汇总。厂商名称是选择示例，不表示每家每类信息均完整覆盖。

### 1.3 假设与成功标准

假设：持续跟踪多个平台的人愿意为筛选、条件核对和报告整理付费。竞品说明这种交付形式存在，不能替代本产品验证。

首轮观察至少4个出版周期，以下均为建议目标，不是现状数据：

- 接触10–15位目标用户，至少5位完整体验两期，记录其具体用途与未满足需求。
- 至少3位实际付费试点；首轮结束时至少2位选择继续付费。人数太少不能据此估算稳定转化率。
- 完成4期按规则发布的内容，所有关键结论具有可回查证据；发现的事实错误均有修订记录。
- 记录每期编辑与审核工时、投递成本、用户使用价值和续费理由，决定是否扩展。

## 2. 内容与权益

| 内容/能力 | 免费/匿名基础 | 专业订阅有效期内 |
| --- | --- | --- |
| 当前价格、适用条件、普通动态、来源与必要更正 | 保留现有访问 | 相同基础访问 |
| 已公开历史、正式周报、账号关注及标准每日提醒 | 保留现有行为与额度 | 相同基础能力 |
| 新专业简报 | 样例或公开预览 | 完整阅读、按关注范围查看、导出 |
| 新重要变化详解 | 公共事实摘要、标题与预览 | 完整对照、适用范围、历史关联、待核对事项 |
| 新历史/跨平台专题 | 主题与范围预览 | 完整分析、表格、时间线及导出 |
| 接入 | 原匿名 REST/MCP/Skill 和公共 RSS | 新专业内容查询、专属 RSS；网页与接入权益一致 |

不把公开历史重新加锁；不以延迟当前事实、更正或现有免费提醒作为主要收费差异。个人免费关注不因专业订阅停用而被删除。

### 2.1 首版专业内容

1. 每周简报：本周重点、分类清单、详解、历史/横向对照、待核对事项、证据。
2. 重要变化详解：金额/计费条件、正式模型生命周期、可核实的服务能力变化；普通网页修改不自动升为重要变化。
3. 专题：同一模型跨平台条件对照、指定厂商在已记录期间的变化回顾。每期按需要引用已有专题，不承诺每周都有一个新专题。

专属简报从统一专业内容库筛选与组合，不给每人另写一份研究报告。研究结论需要编辑复核；LLM 可以辅助起草和分类，但未经审核不得发布。所有模板和判据见 content-spec.md。

## 3. 完整用户场景

1. 免费用户在首页、模型页或专业情报栏目看到公开预览和完整样例，理解免费/专业差异。
2. 登录并申请试点；运营沟通服务内容、报价、有效期与交付时间，记录申请及开通结果。首版人工收款与开通，无自动扣款。
3. 开通后配置专业订阅范围，预览匹配结果；可导入已有关注，但需要确认，不自动启用新邮件。
4. 发布日形成经审核的专业周简报；网站可读。用户选择邮件后收到个人范围简报；选择 RSS/Agent 时在对应客户端使用。
5. 用户展开详解/专题、核对证据、导出用于内部讨论；可以反馈错误或标记本期是否用于工作。
6. 修改范围应用于后续简报；已经发布给该用户的简报保持原范围与版本，可切换到当前修订。
7. 到期后暂停专业全文、专业导出和新专业投递；继续保留免费访问、普通每日提醒、账户与范围配置。续期开通后无需重新建账号或重装 Skill。

## 5. 页面、字段与交互

### 5.1 专业情报栏目（拟 `/pro/`）

包含产品用途、免费/专业对照、真实完整样例、本期公开预览、数据覆盖、服务时间和试点申请。登录用户显示“申请试点”或“查看我的简报”。价格未确定时明确是试点沟通，不显示虚假价格或立即购买。

预览与专业正文分开管理；免费访客获得独立预览数据，不下载正文后通过 CSS 遮挡。旧公开栏目入口保留。中文专业正文为首版编辑语言；英文入口标注正文语言，未经核验不自动承诺英文研究报告。

申请字段：工作场景（必填，限500字）、关注对象（必填，可选现有目录）、愿意体验的方式（必填）、联系邮箱（默认为账户邮箱，可修改为验证后的地址）。不要求供应商密钥、实际账单或个人敏感资料。重复申请展示当前处理状态。

### 5.2 账户中的专业订阅

| 字段 | 规则与默认 |
| --- | --- |
| 厂商 | 来自已支持目录；可多选；默认未选 |
| 模型/系列 | 使用明确身份目录；可多选；默认未选 |
| 主题 | 价格、计费条件、模型生命周期、服务能力；默认价格与计费条件；至少一项 |
| 投递方式 | 网站始终可用；邮件默认关闭；RSS/Agent需用户主动配置 |
| 范围状态 | 显示匹配示例、已覆盖信源与当前缺口 |

对象规则：厂商与模型/系列取并集，再与主题条件取交集。同一条内容只出现一次。至少选择一个对象，空配置不自动代表全平台。厂商级变化可以进入厂商范围；模型范围只纳入已明确关联的内容，不推断平台变化涉及全部模型。

保存前显示“将跟踪的范围”和样例。无匹配内容仍可保存有效配置，但明确目前暂无记录；目录失效项保留名称及不可用说明，用户可移除。关闭专业邮件不改标准每日邮件开关，两个开关分别命名。

### 5.3 简报、详解与专题页

列表展示标题、范围、出版时间、正文语言、覆盖状态、修订/撤回标识。详情展示报告正文、比较条件、时间精度、证据引用、关联内容和反馈入口。图表只使用可比较观察点，不填补缺测值；表格对不可比较记录分组展示。

用户可在本期简报中进入详解或专题，并返回原范围。首次范围配置后可浏览最新已发布内容；邮件只从下一次正式发布起发送，不补发历史邮件。

导出首版支持 Markdown 与对照表 CSV，包含范围、时期、数据截至、版本、限制和来源。图像/PDF/团队模板后置。导出权限在请求时校验；个人资料导出与专业报告导出分开。

### 5.4 凭证管理

账户显示凭证名称、用途、创建/到期/最近使用时间与撤销操作。创建时仅显示完整通用访问 Token 一次，默认30天到期，可选更短期限；丢失后重新生成，服务端仅保留校验值。可分别给不同客户端建凭证，不要求同一密钥共享所有工具。

RSS 地址采用仅能读取一个个人订阅的独立凭证；用户可以重新复制或轮换私有地址，存储保护方案在技术规格明确。轮换使旧地址失效，不影响通用 Token 和账号会话。RSS 凭证不能用于 REST/MCP 或个人资料接口。用户主动撤销专业权益后，所有专业内容访问立即停止；Token到期仅影响该客户端，不改账户套餐。

## 6. 出版与内容运营

### 6.1 周期建议（待确认默认）

每周二北京时间10:00发布，统计窗口为前一周周一00:00至本周周一00:00，采用半开区间。周一留给核验和编辑。页面按用户显示时区呈现准确时间；来源只有日期精度时保留日期精度，不能补造小时。

报告区分内容统计窗口、数据截至、审核时间、出版时间。首次覆盖不足一周时标为首期/部分覆盖。延误时显示状态和预计更新时间，不将旧简报改日期冒充本期。出现已采集的重要更正不等下个周周期。

### 6.2 生产流程

采集及现有归档 → 候选变化 → 事实核验/去重/条件比较 → 详解或专题草稿 → 人工审核 → 发布本期统一内容 → 按用户范围组合 → 各渠道分发。

内容状态为 draft / in_review / published / revised / withdrawn。发布版本不可原地覆盖，修订保留历史与原因。首版允许一个维护者同时编辑和审核，但必须完成检查并留下记录；产能依赖不能写成无人值守。

每条入选内容记录“为何值得关注”和依据。金额可比时允许计算百分比；币种、单位、地区、上下文、档位、缓存或时间条件不一致时不算单一涨跌率。前值为0或未知时不计算百分比。重要性由可说明的判据和编辑确认，不生成无依据的精确评分。

无新重要变化与采集失败分开：前者交付说明范围与统计期的空期简报；后者显示覆盖受限或延迟，不宣称全平台无变化。

### 6.3 更正

普通排版调整更新版本和修订说明，不重复通知。金额、适用范围、生命周期等关键事实错误发布更正；已收到相关简报的用户可收到一次事务性更正通知（独立于下一期新简报）。已彻底退出专业邮件、更改收件地址或撤销投递授权者以站内/查询提示为准，不绕过退订。

所有专业详情、查询、导出均显示当前状态；历史简报中已撤回的引用标明失效，不能继续支持原结论。公共事实有错误时，同步更正公共层，不只修付费报告。RSS与邮件客户端已缓存的副本不可保证召回。

## 7. 权益与渠道规则

### 7.1 权益

首版按账户开通个人专业订阅，区分 pending / active / expired / revoked，开始时间之前不生效。运营记录开始与到期时间、来源（试点/人工收款）、开通/修改/撤销原因和操作者；服务端统一检查，不能仅修改展示文字或依靠用户上传plan。

有效期内可读取库中已发布专业内容和本人已组合简报；不能读其他人的个人范围或报告。到期保存范围和历史索引，但停止取得全文、新导出和新投递。已收到邮件、保存的导出及阅读器缓存无法技术召回，试点服务说明须清楚。

试用默认由运营开通至少覆盖两个正式出版周期的权益；真实价格、付费周期及退款/延误政策需在收费前确定。无自动扣款、无默认自动续费。

### 7.2 渠道

| 渠道 | 认证 | 内容交付 |
| --- | --- | --- |
| 网站 | 现有账号会话 | 受保护全文、范围简报、详解与专题 |
| 邮件 | 开通权益 + 主动订阅 + 发布时重新校验 | 本人本期简报要点、主要对照与完整阅读链接；过长时明确截断 |
| REST / MCP | 通用访问 Token；每次请求再查权益 | 新增专业目录/简报/详解/专题查询；返回相同版本和证据 |
| Agent Skill | 复用 REST/MCP 客户端凭证 | 配置后查询已发布内容；不内置密钥、不将凭证粘贴进提示词 |
| 私有 RSS | 独立订阅凭证 | 本人范围专业更新摘要与详情链接；无需阅读器设置请求头 |

不强制现有免费端点认证，不修改现有五个公共MCP工具和公共RSS语义。专业查询新增能力及合同，在技术规格中定名。Agent查找已发布分析，不承诺任意问题都能现场生成审核后的研究。

无凭证返回缺少认证，有凭证但无权益返回权益不足，已撤销凭证返回凭证失效；对外不泄露其他账户的内容是否存在。网站可引导登录/申请；客户端错误给出恢复步骤，不回退到模型自行编造答案。

新专业全文不放匿名静态构建、公开JSON、旧匿名接口、前端脚本或公共RSS。专业页只预渲染公共壳与独立预览，正文走受保护服务。授权响应默认私有且禁止公共缓存；凭证不进入日志、分析事件、错误追踪或共享缓存键。

## 8. 主要业务规则

| 编号 | 规则 |

| BR-11 | 人工开通和撤销留记录；到期不删除个人配置，续期恢复访问 |

## 9. 指标与验证

漏斗：专业预览 → 登录/申请 → 权益开通 → 完成范围配置 → 首份简报使用 → 重复使用 → 实际付费/续费。基线未建立，不能编造当前转化率。

| 指标 | 定义/用途 |
| --- | --- |
| 激活 | 权益开通后配置范围且阅读/查询/导出首份简报；邮件服务接受请求不算阅读 |
| 持续使用 | 在不同出版周期阅读/查询/导出专业内容的账户数 |
| 付费与续费 | 已核实收款与续期记录，区分免费试用和真实付费 |
| 工作价值 | 用户反馈的实际内部讨论、选型或研究用途；定性回访核实 |
| 内容质量 | 证据缺失、事实更正、误归属和覆盖受限的数量与处理结果 |
| 运营成本 | 每期编辑/审核时间、邮件及计算开销、人工支持时间 |

全渠道使用专业内容ID/版本计量；分析事件不采集邮箱、Token、私有RSS完整地址或正文。阅读来源用网站/REST/MCP/RSS/邮件链接等粗粒度分类，RSS拉取不等于人类阅读。用户反馈以具体用途为主，不以打开率替代付费验证。

## 10. 验收与非功能要求

- 三类内容、证据、审核和版本规则可用；展示覆盖不足的首期与空期结果。
- 同一账户各渠道读取的内容与修订状态一致；到期/撤销/隔离测试无越权。
- 专业正文无法通过静态文件、匿名接口或公共缓存获取；预览不夹带正文。
- Token轮换、私有RSS撤销和错误恢复明确；至少验证两类现有Agent客户端与一个实际RSS阅读器，凭证配置需兼容。
- 发布重跑、邮件失败重试、范围修改、到期和撤回均有验收；沿用原投递去重限制，不能假定外部邮件永久幂等。
- 现有登录、免费提醒、账号状态保存和REST/MCP/RSS/Skill公开合同回归通过。
- 桌面、手机、键盘可完成核心场景；加载、无匹配、到期、目录失效、服务失败有明确状态。
- 试点期记录可用性和查询时延，常规专业查询建议95%在2秒内响应；不以平均时延掩盖失败，不牺牲鉴权换性能。
- 数据与新权益备份可恢复；新schema采用兼容迁移，回滚代码不回滚已开通权益与内容版本。

## 11. 不在首版范围

模型调用/聚合API、自动支付和扣款、多席位团队、任意定制咨询、实时发布承诺、独家内幕、趋势预测、独立性能评测、真实账单接入、自动生成未经审核的用户专属研究，以及把免费功能改为收费。
