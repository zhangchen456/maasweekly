# 开发与本地验收

2026-10-03。第一版开发已形成可验收候选；生产发布、收费、真实收件人邮件均未执行。使用已有发布数据、隔离SQLite账户、受控本地审核样例和Chromium。现有工作区的时区/账号运维并行改动保留，没有替换或回滚。

## 已实现

- 专业内容库：详解/对照/简报结构，来源、条件、局限、范围、覆盖、统计期次；审核、不可覆盖版本、出版、更正/撤回及运营留痕。正式出版加载校验过的目录与证据，模型归属须有明确记录。
- 专业权益：人工开通/撤销、起止日期；服务端逐次校验，免费/到期/撤销及跨用户读取隔离；原账号与免费提醒保留。
- 网站/pro/：公开目录和完整公开样例，申请、受保护阅读、Markdown/CSV导出、个人范围及独立专业邮件开关、报告索引。
- 个人简报：对象并集/主题交集、范围与选中版本快照、正常空结果/覆盖失败区分；读取显示最新修订及撤回。
- 邮件：独立队列、幂等/租约/冻结重试、23小时未知投递转review；关键更正及同版本撤回分开通知，发送前重新验权/检查退订。
- 外部接入：只读通用Token、默认30天有效、哈希存储、撤销/最近使用；独立私有RSS加密存储与轮换；专业MCP三工具使用独立/api/pro/mcp，公共五工具保持原合同；Skill配置与失败恢复说明。
- 运营CLI、聚合事件指标、部署路由、备份/回滚说明；6份真实归档依据的待审草稿（3详解、2条件对照、1完整公开结构样例）。

## 验证结果

API完整回归90/90，公共MCP回归13/13。最后修改后的专业回归8/8，覆盖审核状态/版本、精确范围、凭证用途与加密/轮换、到期/撤销、报告快照与账户隔离、关键更正后同版本撤回、独立退订、幂等/未知投递、HTTP/MCP与RSS权限、追加迁移重启与免费状态保留。

网站静态构建及多语言/导航回归通过，现有观察/价格归档门禁通过，Skill发布包校验通过。反向代理激活脚本bash语法通过；git diff --check通过。静态专业入口和脚本不包含专业样例正文，目录响应只有预览；匿名/免费接口测试无法读取专业正文。

[browser.json](browser.json)：真实本地API与Chromium验证游客、免费和有效专业账户，公开样例可读，专业全文只对有效账户可读；范围保存、凭证生成/撤销、个人报告打开通过。桌面与390px手机无横向溢出、无pageerror；私有RSS的实际本地响应通过XML解析。10次本机小样本读取的观测P95为2.23ms，这不是生产或大内容库性能基线。

## 待上线验收与商业运营

尚未宣称正式上线。上线前确认编辑/审核承担者和实际出版安排、试点报价/服务期/延期退款约定、首批支持范围。样例截至观察日且统计周未结束，不能当作正式一期发送。

发布候选需按既有上线流程备份账号库、验证生产私有缓存/权限，使用已授权试点邮箱验收实际收信；还需至少两类实际Agent客户端及一个真实RSS阅读器。现有结果是本地协议与浏览器验收，不冒充这些真实使用验收。

未安装定时任务或自动收款。运营可先用CLI走审核出版、组合和投递流程；价格未确定不影响开发，但收费试点前必须明确。目标用户反馈、至少两个周期体验和后续四期付费验证仍属于运营工作。
