# 用户故事与验收

版本：0.0.1｜状态：待评审｜日期：2026-10-03。业务基线为 product-plan.md 的 BR-01 至 BR-12。

## Epic 假设

对于持续跟踪多家MaaS厂商的产品经理和技术负责人，提供经审核的指定范围周简报、重要变化详解和专题，会减少自行查阅/比较的工作，并产生付费及持续订阅意愿。以实际工作用途、真实付费、至少两个出版周期的使用和续费验证；不能以访问量或Token数量代替商业价值。

## US-01：判断专业内容是否适合自己（P0）

作为需要比较厂商变化的产品经理，我想先看完整样例和免费/专业对照，以便判断是否值得申请。

- Given 未登录或免费账户，When 打开专业栏目，Then 能读明确选作免费样例的完整内容及其范围/来源。
- Given 免费账户且目标内容非免费样例，When 打开专业详解，Then 只取得独立预览和申请入口，响应中不包含专业全文。

## US-02：申请试点（P0）

作为有明确跟踪需求的技术负责人，我想提交工作场景和关注对象，以便与运营确认服务及报价。

- Given 已登录且必填信息有效，When 提交申请，Then 记录申请并显示处理状态。
- Given 已有待处理申请，When 再次提交相同申请，Then 显示既有状态，不创建重复处理任务。

## US-03：人工开通有效权益（P0）

作为试点运营者，我想为已确认客户设置服务期，以便准确履行付费交付。

- Given 有权限的运营者及明确开始/到期时间，When 开通权益，Then 留下账户、周期、来源和操作者记录并按开始时间生效。
- Given 普通账户，When 试图改自己的套餐字段，Then 权益保持不变且写入被拒绝。

## US-04：选择跟踪范围（P0）

作为专业订阅者，我想选厂商、模型/系列和主题，以便简报只包含相关内容。

- Given 有有效专业权益和至少一个对象及一个主题，When 保存范围，Then 按对象并集与主题交集生成匹配预览并持久保存。
- Given 未选择任何对象，When 保存，Then 明确要求选择对象，不默认全平台。
- Given 内容仅关联厂商，When 预览单一模型范围，Then 该内容不被推断为模型变化。

## US-05：导入已有关注（P0）

作为已使用免费关注的订阅者，我想复用已有对象，以便减少重复选择。

- Given 已有关注列表，When 选择导入并确认，Then 导入可映射对象并显示不可用项。
- Given 未授权专业邮件，When 导入关注，Then 专业邮件仍关闭。

## US-06：取得本期简报（P0）

作为专业订阅者，我想读到有重点、有条件对照和证据的周简报，以便用于内部讨论。

- Given 已审核并发布的本期内容，When 打开个人简报，Then 读到按范围快照组合的完整报告及期号/版本/数据截至。
- Given 无已核验匹配重要变化且覆盖正常，When 出版本期，Then 显示范围内未观察到匹配重点的空期简报。
- Given 关键采集源失败，When 出版本期，Then 报告标为覆盖受限并列缺口，不写全平台无变化。

## US-07：核对详解与专题（P0）

作为行业研究人员，我想查看对照条件和来源，以便复核结论后引用。

- Given 可比较的同条件价格记录，When 查看对照，Then 前后值、口径、时间及证据明确可查。
- Given 地区/档位/单位等条件不一致，When 查看专题，Then 不可比项单列，不能显示合并的涨跌率或最低价结论。
- Given 历史覆盖不足，When 查看时间线，Then 缺失区段明确，不能补造趋势点。

## US-08：更改后续范围（P0）

作为专业订阅者，我想调整下一期范围，以便跟随工作重点变化。

- Given 已有出版简报，When 修改订阅范围，Then 新范围应用于后续出版，旧报告的范围快照不被覆盖。

## US-09：选择邮件并避免重复（P0）

作为专业订阅者，我想主动选择专业邮件，以便在合适渠道持续获取报告。

- Given 未开启专业邮件，When 出版本期，Then 不发送新专业邮件。
- Given 已开启且发布/投递时权益有效，When 投递同账户同期同版本任务被重跑，Then 不重复发出普通简报。
- Given 关闭专业邮件，When 下一期发布，Then 专业邮件停止且免费每日提醒的设置不变。
- Given 投递暂时失败，When 执行重试，Then 使用既有任务身份与内容，超过外部幂等保护的不确定任务停止自动重发并提示复核。

## US-10：接收更正（P0）

作为曾使用专业结论的订阅者，我想知道关键事实被更正，以便修正自己的材料。

- Given 关键事实错误且已有被引用简报，When 发布修订，Then 相关报告显示更正及原因，查询和导出反映当前状态。
- Given 同次更正通知已处理，When 再次执行分发，Then 不重复通知。
- Given 用户已退订专业邮件，When 发布更正，Then 保留站内/查询状态提示，不绕过退订发信。

## US-11：在Agent/MCP中读取专业内容（P0）

作为用Agent研究变化的订阅者，我想配置客户端凭证，以便查询已发布专业分析。

- Given 有效Token和专业权益，When 查询同一报告，Then 与网站返回相同内容版本、范围、证据与修订状态。
- Given 无凭证，When 请求专业全文，Then 得到认证与恢复说明，不泄露正文。
- Given 使用原公共MCP工具，When 匿名查询基础数据，Then 原有行为继续可用。

## US-12：管理客户端凭证（P0）

作为在多个工具中使用订阅的用户，我想分别命名和撤销凭证，以便停止单一客户端访问。

- Given 新建通用Token，When 创建成功，Then 只在创建时显示完整Token，并显示用途及到期时间。
- Given 已撤销或过期凭证，When 再次请求，Then 禁止新的专业内容访问且不改其他凭证。
- Given 通用Token丢失，When 查看凭证列表，Then 不能重新取回原值，可创建替代并撤销旧值。

## US-13：在RSS阅读器订阅（P0）

作为使用阅读器的专业订阅者，我想复制专属订阅地址，以便读取本范围的更新。

- Given 独立RSS凭证，When 阅读器拉取，Then 获得本人范围的专业更新摘要和详情入口。
- Given 轮换私有RSS地址，When 旧地址再拉取，Then 失效且通用Token保持原状态。
- Given RSS凭证，When 请求其他内容或个人资料接口，Then 不获授权。

## US-14：导出工作材料（P0）

作为产品经理，我想导出报告和对照表，以便在内部讨论中引用。

- Given 有效专业权益，When 导出Markdown/CSV，Then 导出包含范围、时期、版本、来源及限制，表格条件不丢失。
- Given 导出请求期间权益失效，When 服务处理请求，Then 拒绝新的专业导出，个人资料导出仍可用。

## US-15：到期后保留免费使用（P0）

作为暂不续费的用户，我想保留账户和关注，以便继续使用基础功能。

- Given 专业权益到期，When 请求专业正文或投递新一期，Then 专业访问/新投递停止并给续期路径。
- Given 同一到期账户，When 使用免费关注/提醒/公共查询，Then 既有免费能力及个人设置保持。
- Given 再次开通，When 登录或使用尚有效Token，Then 恢复专业访问且无需重建范围。

## US-16：不能跨账户读取（P0）

作为专业订阅者，我想让个人跟踪范围与报告仅由本人访问，以便避免配置被其他人读取。

- Given 用户A的有效凭证，When 请求用户B的个人报告/范围，Then 不返回内容及可用于枚举的存在信息。
- Given 同一公开专业文章，When 两个有效订阅者读取，Then 可以共享统一文章，但不会暴露彼此的个人数据。

## US-17：审核后发布（P0）

作为内容维护者，我想在发布前检查证据和口径，以便交付可靠报告。

- Given 未审核草稿，When 发起出版，Then 拒绝对外发布和分发。
- Given 证据/归属/时间/条件已核验并记录审核，When 发布，Then 创建稳定内容ID与不可覆盖版本。
- Given 已撤回的依据，When 查询引用它的报告，Then 显示引用失效，不能继续作为有效结论。

## US-18：了解实际使用与成本（P0）

作为运营者，我想查看跨渠道使用及编辑工时，以便决定是否扩大付费产品。

- Given 有报告使用事件，When 汇总漏斗，Then 按稳定内容ID和账户去重，区分申请、试用、付费与续费。
- Given 仅有邮件发送成功/RSS拉取，When 统计阅读，Then 不直接计为人工阅读或工作价值。
- Given 访问私有RSS或携带Token，When 记录日志/分析事件，Then 不采集完整凭证、邮箱和正文。

## 放行总表

| 检查 | 判据 |
| --- | --- |
| 内容 | 样例、空期、覆盖受限、详解、专题、修订/撤回均有案例 |
| 权益 | 免费、待开始、有效、到期、撤销和跨用户场景均无越权 |
| 交付 | 网站/邮件/REST/MCP/Agent/RSS一致，失败重试与更正可复核 |
| 兼容 | 既有免费公开合同与账号行为回归通过 |
| 运营 | 能人工审核、开通、记录收款、追踪反馈与处理不确定投递 |
| 商业 | 收费前明确价格、周期、覆盖、出版节奏与延误/退款处理 |
