# 完整账户体系

全站中文与英文页面右上角提供邮箱验证码登录。首次验证自动建立账户；登录成功保留当前页面，上方显示昵称（默认邮箱前缀）和账户菜单。移动端入口也保留在第一行右侧。

账户中心提供昵称修改、邮箱与资料建立日期、模型关注与变化历史、每日邮件开关、个人数据导出、退出当前设备和退出所有设备。模型详情页支持直接关注；匿名用户先登录，再完成原先的关注动作。

## 保存范围

- 首页：厂商关注、搜索、平台与变化类型筛选、仅看关注；价格显示币种、自定义参考汇率。
- 价格工作台：厂商、搜索、排序、模型/系列筛选、对比模型及报价条件、组件、输入/输出用量、自定义汇率。
- 全站：显示主题。
- 账户：昵称、模型关注、邮件提醒偏好。

登录操作保存至服务器 SQLite，刷新或使用另一浏览器登录可恢复。匿名操作保存在当前浏览器独立的 guest 空间；切换账户或退出不把账户数据复制给匿名用户。语言仍使用网站原有语言入口。

## 实现与验证

新增 profile/state 表采用加法迁移，保留已有用户、关注和会话。会话使用原有 HttpOnly Cookie；保存接口从会话确定用户身份，并验证允许保存的产品配置与大小。数据导出不包含会话、验证码或退订凭据。

配置写入短暂合并，内部跳转和退出前完成待保存操作；错误显示重试入口。跨页恢复、其他标签页的登录/退出、所有设备退出均使用共享账号客户端。

后端账户测试覆盖持久化、资料验证、非法状态拒绝、用户隔离、数据导出和会话撤销。真实 Chromium 验收使用临时 SQLite 与本地 outbox，不触发外部邮件；脚本为 `scripts/account-browser-smoke.py`，结果见 `acceptance/browser.json`。发布仍通过 main 标准 CI、不可变构建、蓝绿激活与四入口验收。
