## 首页默认语言方案

优先调查服务器可用 GeoIP 数据来源、许可和更新条件，再确定实现；当前没有已核实可用的国家识别来源。

建议保持静态页面，增加站内只读国家入口，使用 Nginx 实际连接地址与本地国家数据库查询。若后续确认存在代理，必须先定义可信代理边界；忽略客户端任意国家头或 X-Forwarded-For。入口仅返回国家代码，不新增原始 IP 采集，不发送到新的第三方定位服务；禁止共享缓存。

浏览器仅在首页无显式语言参数时执行：手动偏好优先，然后国家，最后浏览器首选语言。定位约 1 秒超时，失败仍可浏览。手动选择保存 180 天，显式路径不会永久覆盖偏好；切换中文使用显式参数保证存储不可用时仍无循环。深层链接不自动导航。无 JS 首页保留中文并提供英文链接。

新增入口优先独立于公开 API 合同；配置和服务随 release 管理的具体方式须在实现前确定，避免被激活器的动态 include 覆盖。数据库安装、更新、故障回退和回滚必须有可审查配置与操作说明。国家来源未就绪时不得宣布 IP 功能完成。
