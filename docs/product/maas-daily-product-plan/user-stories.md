# MaaS Daily 用户故事与验收清单

对应产品方案版本：0.0.1。所有故事均为 P0；本文件描述交付要求，不表示已经通过验收。

| 编号 | 用户故事 | 验收条件 |
| --- | --- | --- |
| US-01 | 作为首次访问者，我希望知道怎样接入自己的工具，以便直接开始查询 | 接入页解释四种方式；配置可复制；至少两个已验证客户端有完整说明；真实查询有成功示例 |
| US-02 | 作为 Agent 用户，我希望查询最近某个平台的变化，以便快速了解相关信息 | 平台、关键词、时间过滤正确；显示实际覆盖范围；无记录不等同无变化；支持继续查看 |
| US-03 | 作为开发者，我希望查询模型价格及条件，以便评估是否适用于自己的调用方式 | 原币种、单位、组件、区域及其他条件完整；多候选不擅自择最低；旧数据明确时间 |
| US-04 | 作为研究人员，我希望分享固定的变化地址，以便将其用于报告和讨论 | 改摘要和同日重跑不换链接；超过归档窗口仍可访问；复制成功有反馈 |
| US-05 | 作为核验者，我希望从结论打开证据，以便确认事实是否可信 | 返回真实证据 ID；展示当时摘录、来源和时间；无法完整恢复时明确说明 |
| US-06 | 作为周报读者，我希望获取最新正式周报，以便进行周度回顾 | 只读取正式周报；返回最新期次及链接；不将滚动 7 天摘要称为正式周报 |
| US-07 | 作为阅读器用户，我希望分别订阅变化与周报，以便减少主动回访 | 两个 RSS 均可订阅；GUID 稳定；修改不会生成重复身份；详情链接有效 |
| US-08 | 作为价格使用者，我希望知道数据是否更新失败，以便决定是否采用 | 模拟单源和全源失败有正确提示；沿用旧数据不显示新的观察时间；无可用数据明确失败 |
| US-09 | 作为程序开发者，我希望查询结果和错误可预测，以便稳定接入 | 接口有字段说明；非法参数明确报错；分页不混版；未变化条件请求返回空体 304 |
| US-10 | 作为安装者，我希望更新 Skill 不破坏已有配置，以便安全维护 | 显式目标目录；下载或校验失败保留旧版本；错误目标不覆盖；不要求 sudo |
| US-11 | 作为已引用内容的用户，我希望看到更正说明，以便修正自己的判断 | 更正／撤回后原链接仍存在；说明原因和时间；默认变化列表与详情状态一致 |
| US-12 | 作为维护者，我希望更新或回滚不影响用户引用，以便稳定运行服务 | 发布前完整校验；模拟竞争和失败；旧作业不覆盖新发布；回滚仍可解释所有已公开 ID |
