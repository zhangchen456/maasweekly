## 统计含义

- 原有免费漏斗保持原口径。新增增长区块使用 `growth_start` 之后新注册账号，历史不补造。每次查询显示采集起点；首次行为取注册后7×24小时内最早已记录有效行为，同毫秒按事件名排序；未观察完的账号可能以后产生首次行为。未记录行为不等于没有使用。
- 新增长区块的有效行为：关注、开启提醒、正式内容读取/非样例导出、专业Agent成功，以及浏览器报告的对比/估算完成。服务端读取不代表用户读完。
- 对比：用户主动更改选择后，至少两个模型具有当前图表指标的报价。默认展示和恢复偏好不触发。估算：用户提交用量调整（滑块change或预设按钮），至少两个模型已选，用量有限且非负、合计大于0，并至少生成一个有限成本值。不会上报模型选择、实际用量或计算金额。
- 浏览器完成信号不是服务端核验计算结果：匿名信号仅在Umami中查看（每页每种事件最多一次）；登录后通过同源、需登录的 `/api/account/usage` 保存，仅接受两个事件名，无额外字段；按账号/事件/北京时间日去重。遵守DNT和统计退出，失败不影响功能，不补传匿名事件。
- D7：注册日为第0天，按北京时间第7个日历日发生有效行为。直到该日完整结束才进入成熟分母，至少5个成熟账号才显示比例。独立显示观察中账号，与“7天内跨日回访”分开。
- 推广：保留同标签页30分钟内首次/最近已配置活动编号；内部链接不覆盖，不关联跨设备匿名身份。新注册时事务记录，后续登录不覆盖。未配置/未采集显示unknown，不能解释成全部直接访问。
