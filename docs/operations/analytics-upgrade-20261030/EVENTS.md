# 免费使用和升级意向口径

用户选择：暂不购买 Umami Pro，不接真实收费。

|行为|记录来源|能说明什么|
|---|---|---|
|subscription_click|Umami 前端事件|点击套餐入口，不代表看到页面或开通|
|套餐页浏览|Umami 页面路径 /subscription/ 或 /en/subscription/|查看套餐，不代表付费意愿|
|beta_activation_intent|Umami 前端事件|尚未开通者点击免费 Plus 按钮，登录前可记录；不是开通成功|
|公测激活账号|站内 pro_beta_access|服务端确认免费公测已开通，不是付费|
|model_followed / reminder_enabled|站内 account_value_events|成功关注/开启提醒；重复操作去重，历史不反填|
|核心使用与跨日回访|站内 pro_events|正式内容读取、非样例导出或 Agent 业务成功；回访按北京时间不同日期|

前端可能因 DNT、用户退出统计、网络或脚本阻止漏记；意向次数不能直接作为人数，也不能和站内账号分母拼成个人漏斗。第三方事件不发送账号、邮箱、搜索词或付款数据。Umami 保留后台人工核对，自动同步未配置时显示不可用。

当前没有独立的“愿意按正式价格付费”入口，因此不声称已经测得付费意愿。后续优先来源归因和免费使用漏斗，再设计明确说明目的的意向收集。

## 新注册来源与7天免费使用漏斗

来源保存在当前标签页的 sessionStorage，最长30分钟，从首次观测起计算；仅允许 search/social/ai/referral/campaign/unknown 六类，不存完整 URL、搜索词、活动原文或访客标识。内部链接不覆盖来源。DNT、统计退出或存储不可用时不传来源，服务端记 unknown；unknown 包括直接访问、丢失来源和未采集，不能解读为全部直接访问。来源由客户端提供，仅作描述性统计，不用于权益判断。

新账号创建事务同步保存首次/最近来源；已有账号再次登录不覆盖，不回填历史来源。按首次→最近来源分组。注册日期选定队列，每个账号从注册开始观察7天（结果可延伸至筛选结束日之后，但不晚于查询时刻）；满7天才加入成熟分母。使用包含关注、提醒开启、正式内容阅读/非样例导出和工具业务成功；至少两个北京时间日期有使用算回访。使用率分母为成熟注册账号，使用后回访率分母为已使用账号，分别不足5人时不显示比例。

漏斗覆盖起点取注册采集、关注提醒采集、来源采集三个起点的最大值，旧队列不与新口径混合。只提供注册后的账号漏斗，未把匿名访问、套餐意向或第三方访客拼接成个人全路径。
