## 常用浏览器：一次设置

在 https://daily.maas.click 打开开发者工具的Console，执行：

```js
localStorage.setItem('umami.disabled', '1');
location.reload();
```

读取 `localStorage.getItem('umami.disabled')` 应返回 `1`。刷新后Network不应再加载Umami脚本或发送事件。同一个origin下中文/英文页面共用设置，每个浏览器配置文件/设备需要各自设置，清理网站数据后需重设。不要在cloud.umami.is设置。

恢复（仅在明确要测量自己的浏览时）：`localStorage.removeItem('umami.disabled')`，然后刷新。正常产品使用和登录不受此设置影响。自动化验收如需测试埋点，用本地假服务/测试UUID并拦截外发，不能恢复生产自动化采集去制造验证事件。

本次桌面浏览器连接超时，未替用户设置此标记；不能将此项写成已完成。
