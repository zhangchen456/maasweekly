## 一、重要更新摘要

### 🟡 值得关注

1. **OpenAI Agents API 增加 computer use**：官方文档说明 Agents API 可使用 OpenAI 托管浏览器完成任务，网站访问批准与登录由应用处理。这项能力改变了 Agent 与浏览器环境的连接方式，应用仍需实现相应的批准和登录流程；本期没有对真实网站执行任务的效果测试。

   证据：[2026-09-30 来源记录](/item/obs_4791dfded079c1d4e0e1130d3d5165f111a462edb836bf7a65fd7ceac9038e68/) · [官方来源](https://platform.openai.com/docs/changelog)。

2. **Cohere 发布 Embed 5 嵌入模型系列**：更新日志与模型列表记录 Embed 5 Pro/Fast，支持文本、图像及混合文档输入，128k 上下文，并提供多档向量维度与输出类型。对于现有检索系统，迁移涉及重建向量和匹配维度；厂商关于检索质量的说明需要用自己的文档集验证。

   证据：[2026-09-30 来源记录](/item/obs_2df532a4f57ab88af12d65014a2ac3b5c89e9ed0e0398efac67dd386095a8051/) · [官方来源](https://docs.cohere.com/changelog)。

3. **Anthropic 预告 Sonnet 4.5 在 11 月 30 日退役**：官方公告记录 claude-sonnet-4-5-20250929 计划于 2026 年 11 月 30 日在 Claude API 退役，并建议迁移到 Sonnet 5.5。应在退役日期前安排迁移。迁移还应结合上期记录的 Sonnet 5.5 请求兼容变化。

   证据：[2026-10-01 来源记录](/item/obs_b430bb7e93094c95e3dcbaa684cab49865b04b24715f4529e84542f0661fa5d8/) · [官方来源](https://docs.anthropic.com/en/release-notes/api)。

4. **xAI 语音转写旧模型改由 2.0 服务**：更新日志说明 grok-voice-transcribe-1.0 于 10 月 2 日结束生命周期，旧 slug 请求路由到 grok-voice-transcribe-2.0，价格保持一致。应用应同步更新模型配置，并用现有音频样本核对输出格式与质量。

   证据：[2026-10-03 来源记录](/item/obs_3db8a4529be6c9c1a08d2fb870476b85a26ebbfe86f2607b04aa92dc515f2d0d/) · [官方来源](https://docs.x.ai/docs/release-notes)。

5. **MiniMax 将 Preview 模型入口说明改为 M Plan**：模型列表把 M3.1 Flash Preview 的入口描述从 Token Plan 改为 M Plan 与 MiniMax Code。来源记录能确认入口名称发生修改，但不足以单独证明套餐涨价、权益扩大或按量 API 开放，本期只记录这项范围明确的文档变化。

   证据：[2026-10-01 来源记录](/item/obs_3fd225ab04f787bd68efb780ae24091aceccf3ba8f83ea92078da82a1ca7f87b/) · [官方来源](https://platform.minimaxi.com/docs/guides/models-intro)。
