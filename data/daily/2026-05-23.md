## 🔴 重要更新

### 1. 智谱发布 GLM-5.1 高速版：400 tokens/s 刷新全球 API 速度纪录（5月22日）
- **发布方**: 智谱 AI（02513.HK）
- **核心突破**: 输出速度达 **400 tokens/s**，刷新全球大模型厂商官方 API 速度上限
- **技术特征**:
  - 保留旗舰大模型完整基座能力，同时实现"旗舰级全尺寸能力"与"极致低延迟"并存
  - 支持 200K 超长上下文窗口，最大单次输出达 128K 标记
  - 由智谱 GLM 团队与 TileRT 团队深度联合打造，重构系统级推理生态
- **三层优化架构**:
  1. **推理引擎层**（TileRT 深度定制）：针对 GLM-5.1 架构重写核心推理路径与底层算子
  2. **调度系统层**（智能合并）：动态批处理、请求合并、KV 缓存调度优化
  3. **基础设施层**（集群协同）：推理集群组网部署、网络链路拓扑、超高频负载均衡
- **应用场景**:
  - AI 编程（Coding Agent）：大型工程重构无需空等，函数、接口与底层调用链同步瞬时展开
  - 实时交互与 3D 游戏：完美胜任游戏世界内实时动态生成、网页 UI 即时构建
  - 商业决策集群：30 秒内完成复杂网页 Agent 集群的多人格并行应答
  - 无缝实时语音：语音识别到合成链路延迟无限趋近于零
- **发布背景**: 伴随港股盘中一度飙升超 22%、市值站稳 4500 亿港元关口，智谱官方正式面向企业客户上线

### 2. DeepSeek 联合清华北大推出 DualPath 推理系统（5月20日）
- **发布方**: DeepSeek、清华大学、北京大学
- **核心定位**: 针对智能体场景的全新推理系统，破解长上下文、多轮交互的效率瓶颈
- **技术突破**:
  - 双路径 KV-Cache 加载：利用解码引擎闲置带宽协助预填充引擎拉取数据
  - 自适应请求调度器：实时监控存储网卡队列、GPU 计算负载，动态选择最优数据加载路径
  - VIP 通道优先级机制：GPU 间集体通信走最高优先级，KV-Cache 拉取任务自动避让
- **实测性能**:
  - 离线批处理推理：DeepSeek-V3.2 660B 模型吞吐量最高提升 **1.87 倍**
  - 在线服务推理：并发请求数量平均达到基线系统的 **1.96 倍**，特定负载下可达 **2.25 倍**
  - 1152 张 GPU 超大规模实验：展现接近线性加速比，性能衰减极低
- **行业意义**:
  - 智能体推理最大瓶颈已从算力转向 KV-Cache 数据的 I/O 速度
  - 打破传统数据流向，让闲置资源得以充分利用
  - 软硬件协同设计的教科书级别示范，将成为下一代 AI 基础设施标配

### 3. 腾讯混元游戏视觉生成平台发布（5月20日）
- **发布方**: 腾讯混元团队
- **核心定位**: 首个工业级 AIGC 游戏内容生产引擎
- **技术矩阵**:
  - 四大游戏图像模型：游戏生图大模型底座、特效生成模型、透明图生成模型、角色原画生成模型
  - 五大视频模型：涵盖完整的游戏视频生成能力
- **已上线能力**:
  - **AI 美术管线**：无缝集成多个 AI 工具，"灵感→草图→标准三视图"零跳转完成
  - **实时画布**：边画边看，约一秒内生成结果并同步渲染细节
  - **AI 2D 美术生成**：基于百万级游戏动漫数据训练的垂类模型，精准还原专业术语
  - **角色多视图生成**：上传单张原画即可生成标准三视图及 360° 旋转视频
- **效率提升**:
  - 角色多视图生成耗时：传统 12 小时 → 几分钟到 30 分钟
  - 主体一致性达 99%
  - 已应用于多个头部游戏项目，美术团队效率提升 300%
- **体验地址**: https://hunyuan.tencent.com/game/
