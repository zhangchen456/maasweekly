## 🔴 重要更新

### 1. MiniMax M2 开源发布（5月17日）
- **发布方**: MiniMax
- **核心定位**: 专为 Agent 和代码而生
- **技术亮点**:
  - 仅 Claude Sonnet 4.5 **8% 价格**，推理速度**快接近一倍**
  - 输入 0.3 美金/百万 Token，输出 1.2 美金/百万 Token
  - TPS（每秒输出 Token 数）约 100，还在快速提升
  - 顶级代码能力：在 Claude Code、Cursor、Cline、Kilo Code 等应用中表现卓越
  - 强大 Agentic 表现：出色规划并稳定执行复杂长链条工具调用任务
- **开源方式**: HuggingFace 开源完整模型权重，vLLM 和 SGLang 已提供支持
- **限时免费**: 测试时间延长至 11 月 6 日
- **Agent 产品**: MiniMax Agent（Lightning 高效模式 + Pro 专业模式）
- **榜单表现**: Artificial Analysis 10 个测试集平均分全球前五

### 2. MiniMax M1 开源推理模型发布（5月14日）
- **发布方**: MiniMax
- **核心定位**: 全球首个开源大规模混合架构的推理模型
- **技术亮点**:
  - **百万上下文**: 业内最高 100 万 Token 输入（与 Gemini 2.5 Pro 相同），DeepSeek R1 的 8 倍
  - **8 万推理输出**: 业内最长的 8 万 Token 推理输出
  - **闪电注意力机制**: 独创混合架构，8 万 Token 深度推理仅需 DeepSeek R1 约 30% 算力
  - **CISPO 强化学习算法**: 收敛性能比字节 DAPO 快一倍，优于 DeepSeek 的 GRPO
  - **训练成本**: 强化学习阶段仅用 512 块 H800 三周，成本 53.47 万美金（比预期少一个数量级）
- **性能表现**:
  - SWE-bench: M1-40k 55.6%，M1-80k 56.0%（超越所有开源权重模型）
  - 长上下文理解: 全球排名第二，仅落后 Gemini 2.5 Pro
  - TAU-bench（Agent 工具使用）：领跑所有开源权重模型，战胜 Gemini 2.5 Pro
- **定价**:
  - 0-32k: 输入 0.8 元/百万 Token，输出 8 元/百万 Token
  - 32k-128k: 输入 1.2 元/百万 Token，输出 16 元/百万 Token
  - 128k-1M: 输入 2.4 元/百万 Token，输出 24 元/百万 Token
- **免费使用**: MiniMax APP/Web 不限量免费

### 3. Hailuo 2.3 视频模型升级 + Media Agent 发布（5月17日）
- **发布方**: MiniMax
- **Hailuo 2.3 升级**:
  - 复杂人物肢体动作更流畅自然，精确度和可控性更好
  - 动漫、插画、水墨、游戏 CG 等特殊画风支持效果更佳
  - 物体运动指令响应更加出色
  - 保持 Hailuo 02 既有价格，"加量不加价"
  - 提供 Hailuo 2.3 Fast 模型，最高可降低 50% 成本
- **Media Agent**:
  - 从 Hailuo Video Agent 迭代升级为全模态全能创作
  - "一键成片"：输入内容，自动匹配多模态模型，无需手动剪辑
  - 专业创作者可分布创作，自由上传图片、视频、音频
  - 后续版本支持画布中与 Agent 调整细节，"对话即创作"

## 📈 行业趋势分析

### 1. 开源推理模型成为新战场
- MiniMax M1/M2 双模型开源，百万上下文 + Agent 能力
- DeepSeek R1 的 30% 算力完成 8 万 Token 推理，成本优势显著
- 开源模型从"能力追赶"转向"场景定义"：M1 定位推理，M2 定位 Agent/代码

### 2. Agent 成为模型能力核心指标
- MiniMax M2 专为 Agent 和代码设计，强调工具调用、长链条任务
- 火山引擎推出完整 Agent 产品（OpenClaw、HiAgent）
- Agent 能力测试（TAU-bench）成为新榜单维度

### 3. 视频生成进入"加量不加价"阶段
- Hailuo 2.3 升级但保持原价，Fast 版最高降 50% 成本
- Media Agent 推动"一键成片"，多模态融合创作成趋势
- AI 视频从生成工具转向创作平台

### 4. MaaS 飞轮效应验证
- 火山引擎市场份额 49.5%，市场扩容但领跑者份额未稀释
- 规模效应成为核心竞争力：调用规模越大，成本越低
- 140 家万亿客户验证 Agent 基础设施化趋势
