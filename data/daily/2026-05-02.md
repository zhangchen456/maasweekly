## 🔥 重要更新

### 1. 腾讯混元 Hy3 Preview 发布（4月23日）

**核心亮点**:
- 快慢思维融合 MoE 架构，总参数 295B，激活参数 21B
- 256K 上下文窗口
- 192 路专家与 top-8 路由机制
- 姚顺雨主导，三个月完成基础设施重建到上线
- **战略转向**: 不追榜单，追场景，聚焦腾讯核心业务（社交、游戏、广告、企业服务）

**性能表现**:
- 清华数学博士资格考试国内最高分
- SWE-Bench Verified 达 74.4%
- Agent 能力显著提升

**已上线产品**: 腾讯云、元宝、ima、CodeBuddy、WorkBuddy、QQ、QQ浏览器、腾讯文档等

### 2. Kimi K2.6 发布并开源（4月20日）

**核心亮点**:
- 参数量 1T (A32B)，业界总参数量最大的开源模型
- 256K 上下文窗口
- Agent 集群架构，支持 300 个子 Agent 并行协作（从 K2.5 的 100 个提升）
- 单次可协调 4000 个协作步骤
- 增强长程编码能力和 Agent 自主执行能力

**已上线**: kimi.com、Kimi 应用、Kimi API、Kimi Code 编程助手

### 3. MiniMax M2.5 发布

**核心亮点**:
- SWE-Bench Verified 80.2%，Multi-SWE-Bench 51.3%，BrowseComp 76.3%
- "像架构师一样思考和构建"能力，原生 Spec 行为
- 支持 10+ 编程语言，覆盖全栈项目
- 100 TPS 推理速度，两倍于主流模型

**成本优势**:
- 100 TPS 版本: 输入 0.3 美金/百万 token，输出 2.4 美金/百万 token
- 50 TPS 版本: 输出价格是 Opus/Gemini/GPT 的 1/10-1/20
- 连续工作一小时仅需 1 美金（100 TPS）或 0.3 美金（50 TPS）
- 1 万美金可让 4 个 Agent 连续工作一年

**MiniMax Agent**:
- 深度集成 Office Skills（Word、PPT、Excel）
- 用户已构建 1 万多个专家
- 内部 30% 任务由 M2.5 自主完成，代码生成占新提交代码的 80%

### 4. 智谱 GLM-5.1 发布（4月8日）

**核心亮点**:
- MIT 许可证全权开源
- 完全基于约 10 万个华为昇腾 910B 芯片训练
- 使用 MindSpore 深度学习框架
- 国产算力训练的最大规模开源模型之一

### 5. 百度 Ernie 5.0 发布（2026年1月）

**核心亮点**:
- 统一自回归架构，原生全模态建模
- 超稀疏 MoE 架构
- 总参数规模超过 2.4T，激活参数比例低于 3%
