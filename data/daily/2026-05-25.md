## 🔴 重要更新

### 1. 腾讯混元开源世界模型 HY-World 2.0：从"看电影"到"造世界"（5月24日）
- **发布方**: 腾讯混元团队
- **核心定位**: 首个开源的 3D 世界模型框架，生成可编辑、可持久化的 3D 资产
- **技术突破**:
  - 多模态输入：支持文本、单视图图像、多视图图像、视频
  - 双核心能力：世界生成（文本/图像→3D世界）+ 世界重建（多视图/视频→3D）
  - 直接生成 3D 资产（Mesh/3DGS/点云），可导入 Unity/Unreal Engine/Isaac Sim
- **模型矩阵**:
  - **HY-Pano-2.0**: 文本/图像→360°全景（~80B 参数）
  - **WorldStereo-2**: 全景→3DGS 世界（~17B 参数）
  - **WorldMirror-2**: 多视图/视频→3D 重建（~1.2B 参数）
- **行业意义**:
  - 与纯视频世界模型（Genie 3、HY-World 1.5）不同，HY-World 2.0 生成真实 3D 资产
  - 解决视频世界模型"播放结束即消失"的痛点
  - 从"看一部电影"进化到"构建一个可玩的游戏"
- **开源地址**: https://github.com/Tencent-Hunyuan/HY-World-2.0

### 2. DeepSeek V4-Pro 确认永久降价：创全球大模型价格新低（5月22日）
- **发布方**: DeepSeek（深度求索）
- **核心变化**: V4-Pro 模型 API 价格将于 2026 年 5 月 31 日结束 2.5 折优惠活动后，正式调整为原定价的 1/4
- **新定价**:
  - 输入（缓存命中）: 0.025 元/百万 tokens
  - 输入（缓存未命中）: 3 元/百万 tokens
  - 输出: 6 元/百万 tokens
- **行业意义**:
  - 创全球大模型价格新低，且未设置时限
  - 这已经是 DeepSeek 在一个月内的第四次调价
  - 从"限时优惠"转向"永久降价"，确立极致性价比定位
- **技术支撑**:
  - V4-Pro 采用创新混合注意力架构，百万 Token 上下文场景下单 Token 推理 FLOPs 降至前代模型的 27%
  - KV 缓存占用仅为 10%
  - 全面适配华为昇腾等国产算力平台
- **融资背景**: 同期推进 700 亿元首轮融资，创始人梁文锋明确表态"技术边界拓展是第一要务，而非急于变现"

### 3. 智谱 GLM-5.1 高速版：400 tokens/s 刷新全球 API 速度纪录（5月22日）
- **发布方**: 智谱 AI（02513.HK）
- **核心突破**: 输出速度达 **400 tokens/s**，刷新全球大模型厂商官方 API 速度上限
- **技术特征**:
  - 保留旗舰大模型完整基座能力，同时实现"旗舰级全尺寸能力"与"极致低延迟"并存
  - 支持 200K 超长上下文窗口，最大单次输出达 128K 标记
  - 由智谱 GLM 团队与 TileRT 团队深度联合打造，重构系统级推理生态
- **三层优化架构**:
  1. **推理引擎层**（TileRT 深度定制）：针对 GLM-5.1 架构重写核心推理路径与底层算子
  2. **调度系统层**（智能合并）：动态批处理、请求合并、KV 缓存调度优化
  3. **基础设施层**（集群协同）：推理集群组网部署、网络链路拓扑、超高频负载均衡
- **应用场景**:
  - AI 编程（Coding Agent）：大型工程重构无需空等，函数、接口与底层调用链同步瞬时展开
  - 实时交互与 3D 游戏：完美胜任游戏世界内实时动态生成、网页 UI 即时构建
  - 商业决策集群：30 秒内完成复杂网页 Agent 集群的多人格并行应答
  - 无缝实时语音：语音识别到合成链路延迟无限趋近于零
- **发布背景**: 伴随港股盘中一度飙升超 22%、市值站稳 4500 亿港元关口，智谱官方正式面向企业客户上线

### 4. 大模型行业进入"通胀时代"：涨价与降价并存（5月）
- **行业观察**: 2026 年大模型定价出现分化，告别"价格战"进入"价值战"
- **涨价阵营**:
  - **智谱 AI**: 年内连续多次提价，最高涨幅超过八成，GLM-5.1 发布时再涨 10%
  - **豆包**: 推出付费订阅，标准版 68 元/月、加强版 200 元/月、专业版 500 元/月
  - **Kimi**: API 输入价格上涨 58%
  - **阿里云/腾讯云**: AI 算力相关产品涨价 5%
- **降价阵营**:
  - **DeepSeek**: V4-Pro 永久降价至原价 1/4，缓存命中输入 0.025 元/M tokens
  - **阿里通义**: Qwen-Long 输入价格直降 97%，0.0005 元/千 tokens
- **行业趋势**:
  - 智谱 CEO 张鹏："智能上界决定了定价权，Token 消耗规模决定了价值体量"
  - 从"跑马圈地"进入"差异化定价"商业化深水区
  - 低价格不再是唯一关键指标，价值创造站到 C 位

- **关键发现**: Google DeepMind 发布《Towards a Science of Scaling Agent Systems》
  - **规模悖论**: 任务越复杂，Agent 越多，死得越快
  - **黄金分割点**: 3-4 个智能体是当前技术下的上限
  - **能力门槛**: 单智能体准确率超过 45% 时，增加智能体数量通常会带来负收益
  - **效率暴跌**: 中心化架构 Token 效率仅为单智能体的 1/3
- **CMU 等机构联合发布《Agent Harness Engineering》**:
  - 线束工程（Harness Engineering）成为 2026 年新范式
  - 从提示词工程→上下文工程→线束工程的三阶段演进
  - 核心模块：执行、工具、上下文、生命周期、可观测性、评测、治理

- 智能 Agent 场景对低延迟的需求驱动推理架构革新

### 3. 定价策略分化加剧
- DeepSeek：极致性价比，永久降价至原价 1/4

- 阿里通义：Qwen-Long 直降 97%，击穿全球底价
- 从"同质化竞争"到"差异化定价"

### 4. Agent 工程化进入新阶段
- 从提示词工程→上下文工程→线束工程
- 3-4 个智能体是当前技术的"黄金分割点"
- 多智能体系统存在"规模悖论"
- 线束工程（Harness Engineering）成为 Agent 稳定性的硬约束

### 5. 软硬件协同优化成标配
