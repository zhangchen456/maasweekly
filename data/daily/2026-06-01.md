## 🟡 跟进报道

### 1. MiniMax M3 系列进入发布准备阶段（跟进 5/27 报道）
- **原报道**: 2026-05-27（官方预告 M3 系列即将发布）
- **新进展**: 技术架构披露，实测数据释放
  - 采用自研稀疏注意力机制
  - 索引分支快速扫描上下文，筛选关键Token
  - 稀疏计算分支进行精准注意力计算
  - 计算量压缩至原来的十分之一甚至更低
  - 预填充速度提升 9.7 倍
  - 解码生成速度提升 15.6 倍
  - 百万Token级长文档算力成本降低 80% 以上
- **架构突破**: 解决传统Transformer O(n²)计算复杂度痛点
- **技术争议**: 稀疏注意力可能在序列维度压缩时丢失关键信息
- **用户反馈**: M2系列存在指令遵循不稳定、幻觉明显、多步骤推理易出错等问题，M3有望系统性改善
- **发布节奏**: 具体技术参数、发布时间尚未公布，预计六月发布潮

### 2. Anthropic Claude Opus 4.8 发布（跟进 5/31 报道）
- **原报道**: 2026-05-31（Claude Opus 4.8 发布）
- **新进展**: 详细功能与测评数据披露
  - **动态工作流（Dynamic Workflows）**: Claude Code 研究预览版功能，单任务可协调数百个并行子智能体
  - **投入控制（Effort Control）**: 用户可直接控制 Claude 为任务投入多少"思考资源"
  - **快速模式大幅降价**: 运行速度提升至常规 2.5 倍，成本仅为前代模型的三分之一
    - Fast Mode 定价：$10/M 输入 + $50/M 输出（原 $30/$150）
    - 常规定价不变：$5/M 输入 + $25/M 输出
  - **"诚实度"大幅提升**: 面对不确定信息时更倾向主动标记疑点
- **测评成绩**:
  - Online-Mind2Web 浏览器智能体基准：84%，优于 Opus 4.7 和 GPT-5.5
  - SWE-Bench Pro: 显著提升
  - 法律智能体基准：首个突破 10% 整体通过率的模型
- **行业意义**: 从"模型能力竞争"进一步迈向"智能体系统竞争"
