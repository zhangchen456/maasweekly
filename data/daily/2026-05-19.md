## 🔴 重要更新

### 1. 豆包大模型 Seed2.0 全系发布（5月18日）
- **发布方**: 火山方舟（字节跳动）
- **核心定位**: 围绕复杂 Agent 使用与大规模生产部署优化
- **四款模型**:
  - **Pro**（doubao-seed-2-0-pro）：旗舰全能，复杂推理与长链路 Agent 任务
    - 定价：输入 3.2 元/百万 Token，输出 16 元/百万 Token
  - **Lite**（doubao-seed-2-0-lite）：均衡型，综合能力超 Seed1.8
    - 定价：输入 0.6 元/百万 Token，输出 3.6 元/百万 Token
  - **Mini**（doubao-seed-2-0-mini）：低时延高并发，256k 上下文
    - 定价：输入 0.2 元/百万 Token，输出 2 元/百万 Token
  - **Code**（doubao-seed-2-0-code）：编程加强版，适配 Claude Code 等 IDE
    - 定价：输入 3.2 元/百万 Token，输出 16 元/百万 Token
- **技术亮点**:
  - 数学与视觉推理：19 项基准中 12 项第一
  - EgoTempo 分数 71.8，超越人类（63.2）
  - HealthBench 排名第一，SuperGPQA 超过 GPT-5.2
  - 长上下文：DUDE、MMLongBench 等业内最佳
  - 视频理解：TVBench、TempCompass、MotionBench 领先
- **成本优势**: 相比同级 GPT 与 Claude，API token 定价低一个数量级
- **接入方式**: 豆包 App「专家」模式、TRAE、火山引擎 API、方舟 Coding Plan
- **资料**: 同步发布 79 页 Model Card

### 2. 智谱 AI 正式启动 IPO（5月18日）
- **辅导机构**: 中金公司
- **预计时间**: 2025 年 10 月完成上市辅导，后续递交 A 股招股书
- **估值**: 超过 200 亿元，国内估值最高创业大模型公司之一
- **里程碑**: 第一家正式启动 IPO 流程的"大模型六小虎"
- **同日发布**: 开源 32B/9B 系列 GLM 模型，启用全新域名"z.ai"
- **技术路线**: 完整对标 OpenAI 模型产品，2025 年主打开源
- **城市合作**: 杭州、珠海、成都多地战略投资
  - 杭州：超 10 亿元战略融资（杭州城投、上城资本）
  - 珠海：华发集团 5 亿元战略投资
  - 成都：高新区 3 亿元战略投资，打造"智谱诸葛大模型"

### 3. 大模型行业集体涨价趋势确认（跟进报道）
- **背景**: 2026 年 2 月 OpenClaw 走红后，Token 消耗量增速远超预期
- **涨价时间线**:
  - 智谱：2 月 12 日 GLM-5 发布时首次提价，3 月 16 日 GLM-5-Turbo 再次提价，累计涨幅 83%
  - 腾讯云：3 月 13 日混元系列调价，部分模型涨幅超 460%
  - 阿里云/百度智能云：3 月 18 日同日发布调价公告，涨幅 5%-34%
- **市场反应**: 智谱涨价 83% 后，调用量增长 400%，需求未萎缩
- **行业数据**: 中国日均 Token 调用量突破 140 万亿，较两年前增长超 1000 倍
- **战略转变**: 从"亏损换规模"到"涨价换利润"，用时不到两年

### 2. Kimi 与 DeepSeek 估值对比分析（跟进融资报道）

  - ARR 已突破 2 亿美元，商业化路径清晰
  - 投后估值约 200 亿美元
  - 阿里为单一最大股东（约 36%），腾讯超额认购
- **DeepSeek**:
  - 首轮外部融资目标 500 亿元，梁文锋个人出资 200 亿（占 40%）
  - 投后估值超 515 亿美元，约为 Kimi 的 2.5 倍
  - 月活 1.27 亿，是 Kimi（900 万）的 14 倍
  - 国家大基金洽谈领投，属性转向"国家战略能力"
- **技术互嵌**: DeepSeek V4 用 Kimi 的 Muon 优化器，Kimi K2 用 DeepSeek 的 MLA
- **估值逻辑**: 资本市场奖励"未来可能成为什么"而非"现在能赚多少钱"

## 📈 行业趋势分析

### 1. 大模型定价权转移
- 从"价格战"到"集体涨价"，用时不到两年
- 智谱涨价 83% 后调用量增长 400%，证明需求刚性
- Token 成为"AI 时代的新货币"（黄仁勋）
- 国产模型从"成本优势"转向"定价权"

### 2. IPO 窗口期开启
- 智谱首家启动 IPO，估值超 200 亿
- 阶跃星辰、MiniMax 或将跟进
- 资本市场对大模型公司估值逻辑分化：
  - 商业化派（Kimi）：看 ARR、付费用户
  - 技术派（DeepSeek）：看生态覆盖、国家战略价值

### 3. Agent 能力成为核心竞争力
- 豆包 Seed2.0 围绕复杂 Agent 优化
- 长链路、多步骤、强约束任务成为测试重点
- EgoTempo 超越人类，视频理解突破
- Agent 工作流 Token 消耗是聊天场景的数十倍

### 4. 国产模型全球渗透加速
- OpenRouter 平台中国模型调用量持续领先美国
- 小米 MiMo-V2-Pro 以 4.82 万亿 Token 位居全平台第一
- 中国模型在 SWE-Bench 编程评测与 Claude 差距缩小到 0.6 个百分点
- "AI 时代的富士康"叙事转向"定价权"叙事
