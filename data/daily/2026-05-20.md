### 2. MiniMax M2.7 发布（5月19日）
- **发布方**: MiniMax
- **核心定位**: 开启模型自我进化，首个模型深度参与迭代自己的模型
- **技术亮点**:
  - **SWE-Pro**: 56.22%，追平 GPT-5.3-Codex
  - **VIBE-Pro**: 55.6%，几乎与 Opus 4.6 持平
  - **Terminal Bench 2**: 57.0%，复杂工程系统深层理解
  - **GDPval-AA**: ELO 1495，开源最高
  - **Toolathon**: 正确率 46.3%，全球第一梯队
  - **MM Claw**: 62.7%，接近 Sonnet 4.6
- **Agent 能力**:
  - 自行构建复杂 Agent Harness
  - Agent Teams 多智能体协作
  - 40 个复杂 skills (> 2000 Token) 保持 97% 遵循率
  - MLE Bench Lite: 三次平均 66.6% 得牌率，仅次于 Opus-4.6 (75.7%)、GPT-5.4 (71.2%)
- **应用场景**:
  - 真实软件工程：日志分析、Bug 定位、代码重构、代码安全、机器学习
  - 专业办公：Word/Excel/PPT 复杂编辑，研报分析与建模
  - 互动娱乐：高情商与人设保持，OpenRoom 开源项目
- **开源项目**: OpenRoom (github.com/MiniMax-AI/OpenRoom)

### 3. MiniMax Mavis Agent 模式发布（5月19日）
- **发布方**: MiniMax
- **核心定位**: "MiniMax as a Jarvis"，Agent Teams 基础设施
- **架构设计**:
  - **Team Engine**: 引擎层面状态机控制
  - **三类核心角色**: Leader（管理）、Worker（执行）、Verifier（验收）
  - **对抗性机制**: Worker 与 Verifier 之间无法"蒙混过关"
- **关键特性**:
  - **上下文隔离**: 每个 Agent Team 只看到相关任务信息
  - **多任务并行**: 支持 8 个任务同时运行，不发生语境错乱
  - **IM 集成**: 支持微信、飞书管道任务分配
  - **Token Plan 与 Agent Plan 合并**: 统一额度，共享使用
- **实测表现**:
  - Agent Team 可持续运行 100+ 轮迭代
  - 生成的财务预算表格、商业计划书、PPT、网页等 10+ 文件

### 5. 基流科技冲刺港股 IPO（4月29日递表）
- **发布方**: 基流科技（AI 算力集群提供商）
- **估值**: 92 亿元（投后估值，D 轮融资后）
- **融资历程**: 成立三年完成 11 轮融资，累计超 22 亿元
- **业绩数据**:

  - 2024/2025 经调整净利润 2030 万/3110 万元
  - 2025 年毛利率 21.8%
- **核心产品**: Galaxy 品牌智算集群（Mercury 算力网络系统 + Venus 智算平台）
- **挑战与风险**:
  - 客户集中度高：2024 年前五大客户收入占比 98.9%，最大客户 59%
  - 经营性现金流连续三年为负：2025 年 -111 万元

  - 依赖智谱 AI 等大客户，面临巨头围堵

### 6. Google Gemini 3.5 发布（5月19日 I/O 大会）
- **发布方**: Google
- **核心模型**:

- **用户规模**: Google 称 Gemini 用户已达 9 亿

## 🟡 跟进报道

### 1. DeepSeek V4 在华为昇腾上跑通（跟进 V4 发布）
- **原报道**: 2026-05-14（DeepSeek V4 API 正式发布）
- **新进展**: 技术报告明确写入华为昇腾 NPU 与英伟达 GPU 并列验证
  - 首个在昇腾平台上原生适配的前沿大模型
  - MoE 细粒度专家并行方案在两个平台验证
  - 通用推理加速 1.50-1.73 倍，强化学习长尾小批次最高加速 1.96 倍
- **黄仁勋评价**: "这是灾难性的"
  - 英伟达护城河不是 GPU 算力本身，而是 CUDA 作为默认起点的软件生态
  - DeepSeek 证明了一条完整的非 CUDA 路径，二十年生态壁垒出现第一道裂缝
- **战略意义**:
  - R1 回答"中国能不能做"，V4 回答"算力封锁下能不能进化"和"能不能赚钱"
  - V4-Pro 定价：Flash 输入 1 元/百万 token，Pro 输入 12 元
  - 比 GPT-5.4 和 Claude Opus 4.6 便宜约 50 倍
