## 🔴 重要更新

### 1. GPT-5.6 预计本周发布（6月22-28日），从"模型"迈向"可执行Agent"（6月19日）
- **发布方**: OpenAI
- **核心事件**: 据科技媒体 testingcatalog 报道，GPT-5.6 系列涵盖 mini、标准版及 Pro 版，最可能发布窗口为 6 月 22 日至 28 日
- **技术升级**:
  - 上下文窗口从 100 万 tokens 扩展至约 150 万 tokens，较 GPT-5.5 提升约 43%
  - 词元效率提升 10% 至 15%，相同费用可处理更多工作量
  - Agent 化能力全面强化：视觉复刻（将设计稿直接还原为可运行代码）、SVG 3D 对象生成、Playwright 浏览器自动化
  - 在智能体编码（agentic coding）场景中，表现据称已优于 Anthropic Mythos 系列
- **定价策略**: token 价格可能仅为 Claude Fable 5 的约三分之一，延续 OpenAI 当前定价优势
- **发布动态**: Polymarket 上该窗口概率一度高达八成，但 X 平台出现不同声音称因内部技术问题推迟，概率降至不足三成
- **首席科学家确认**: Jakub Pachocki 向员工表示 GPT-5.6 是对 GPT-5.5 的"有意义的改进"
- **行业意义**: OpenAI 冲刺 IPO 前的关键产品节点，Agent 能力成为核心竞争维度

### 2. DeepSeek 识图模式正式上线，首次补齐多模态能力空白（6月18日）
- **发布方**: DeepSeek
- **核心事件**: 6 月 18 日，DeepSeek 多模态研究员陈小康（Xiaokang Chen）确认识图模式已在网页和 App 端正式上线
- **技术细节**:
  - "识图模式"与"快速模式"和"专家模式"并列
  - 支持识别和分析图片内容，但暂不支持图片生成（画图）或生成视频
  - 能力边界远超简单的文字提取，具备真正的图像理解能力
  - 背后采用"Thinking with Visual Primitives（以视觉原语思考）"核心框架
- **实测反馈**:
  - 网友测试显示人物识别尚不稳定，多位戴眼镜的知名人物被误识别为"梁文锋"
  - 腾讯马化腾等部分人物可被正确识别
  - 功能处于初始阶段，仍有优化空间
- **行业意义**: DeepSeek 首次补齐多模态能力空白，从纯文本模型向全模态模型迈进

### 3. 豆包任务模式引发"AI代打"热潮，内置虚拟机意外解锁云游戏场景（6月12-20日）
- **发布方**: 火山方舟（字节跳动）
- **核心事件**: 豆包搭载 Agent 能力的"任务模式"大范围上线后，用户发现其内置独立虚拟机可识别网页、模拟点击、自动操作
- **意外场景**:
  - 玩家发现可通过豆包登录云游戏平台（如《明日方舟》《原神》《崩坏：星穹铁道》等）
  - 自动搜索网站、输入账号、过人机验证，用户只需输入收到的验证码
  - 支持云原神、4399 等云游戏平台直接运行
- **官方定位**: 办公生产力工具，内置独立虚拟机专门处理文档表格 PPT
- **实测办公场景**:
  - PPT 智能创作：依据输入主题自动生成逻辑清晰、视觉协调的演示文稿
  - 支持版式重构、图文匹配及文字精修
  - 浏览器内云游戏虚拟机为技术创新突破
- **行业意义**: AI Agent 从办公场景意外延伸至游戏场景，展现通用 Agent 能力的无限可能性

### 4. 腾讯混元 46 个旧版本模型今日正式下线，平台迁移进入最后阶段（6月22日）
- **发布方**: 腾讯混元
- **核心事件**: 原腾讯混元大模型平台 HY2.0、hunyuan-turbos、hunyuan-t1 等 46 个旧版本模型于今日（6 月 22 日）00:00 正式下线
- **下线范围**:
  - HY 2.0 系列：hunyuan-2.0-instruct、hunyuan-2.0-thinking 等
  - TurboS 系列：hunyuan-turbos-latest、turbo-20250226 等十余个版本
  - T1 系列：hunyuan-t1-latest、t1-20250321 等十余个版本
  - 经典系列：hunyuan-standard、hunyuan-pro、hunyuan-lite、hunyuan-code 等
  - 角色扮演系列：hunyuan-role、hunyuan-large-role 等
- **迁移路径**:
  - 所有下线旧模型（除角色扮演类外）统一推荐替代方案为 Hy3 Preview
  - 角色扮演类模型迁移至 hunyuan-role-latest
  - 原"混元大模型 API"和"知识引擎 DeepSeek API 平台"售卖入口已统一收敛到 TokenHub
- **后续节点**: 6 月 26 日智能体开发平台 9 个旧版本模型停服，9 月 30 日原平台全面停服
- **行业意义**: 大模型平台进入快速迭代期，旧版本模型加速淘汰，企业迁移成为必答题

### 5. 智谱 GLM-5.2 正式上线并开源，Code Arena 全球可用模型第一（6月17日）
- **发布方**: 智谱 AI
- **核心事件**: 6 月 17 日，智谱宣布 GLM-5.2 正式上线并开源，模型权重遵循 MIT License
- **技术能力**:
  - 在全球百万用户参与盲测的前端开发评估系统 Code Arena 上，取得全球可用模型第一的表现
  - 专为长程任务能力而生，支持真正可用的 1M 上下文
  - 在 FrontierSWE、Terminal-Bench 等多个权威评测中，与 Claude Opus 4.8 比肩
  - 实测可承载项目级工程上下文，执行更稳定、规范遵循更可靠
- **开源进展**:
  - Hugging Face 与 ModelScope 已上线模型权重
  - vLLM、SGLang、transformers 等主流推理框架已支持
  - GLM-5.2 API 已上线，并纳入 GLM Coding Plan
- **行业意义**: 国产大模型开源生态持续强化，MIT 协议开源进一步推动全球开源生态发展

### 1. 豆包付费订阅即将正式上线，四档方案已曝光（跟进 6/3 报道）
- **原报道**: 2026-06-03（豆包收费版三档订阅方案披露）
- **新进展**: 6 月下旬付费订阅将正式上线，并同期举行 Force 大会公布功能更新
  - 四档收费标准：基础版（免费）、标准版（68 元/月）、加强版（200 元/月）、专业版（500 元/月）
  - 年收费价格：免费、688 元、2048 元、5088 元
  - 免费版可长期免费使用，包含不限次数基础对话、联网搜索、图片与网页问答等
  - 专业版包含软件开发、数据分析、专业设计、流程自动化、金融分析、科学研究等专业服务
- **行业意义**: 国产 AI 应用付费模式即将正式落地，推动行业商业化进程

### 2. Kimi K2.7 Code 高速版持续推广，输出速度达普通版 5-6 倍（跟进 6/15 报道）
- **原报道**: 2026-06-15（Kimi K2.7 Code 高速版上线）
- **新进展**: 高速版持续推广中，技术参数稳定
  - 常规编程场景输出速度约 180 Token/s，短上下文场景可达 260 Token/s
  - 高速版价格为普通版的 2 倍，1M token 标准输入 6.5 元，输出 27 元
  - 平均 Token 消耗减少 30%（相比 K2.6）
- **行业意义**: 编程模型"高速时代"持续演进

### 3. MiniMax M3 开源生态持续扩展（跟进 6/1 报道）
- **原报道**: 2026-06-01（MiniMax M3 正式发布）
- **新进展**: Hugging Face 权重持续下载中，社区反馈积极
  - 总参数约 428B，激活参数约 23B，支持 1M 上下文窗口
  - MSA 稀疏注意力架构：预填充提速 9.7 倍、解码提速 15.6 倍
  - SWE-Bench Pro: 59.0%，Terminal Bench 2.1: 66.0%
- **行业意义**: 国产开源三强格局（GLM-5.2、MiniMax M3、Kimi K2.7 Code）持续强化

### 4. Anthropic Fable 5/Mythos 5 遭美国政府出口管制封禁持续（跟进 6/13 报道）
- **原报道**: 2026-06-13（Claude Fable 5/Mythos 5 遭封禁）
- **新进展**: 封禁持续，行业影响扩大
  - 6 月 12 日遭美国政府出口管制，全面封禁
  - 美国商务部要求暂停所有外国人使用 Fable 5 与 Mythos 5
  - Anthropic 被迫对两款最先进 AI 模型实施全面访问限制
  - GPT-5.6 发布也因此面临更大的监管不确定性
- **行业意义**: 前沿 AI 模型首次遭遇政府强制封禁，开创监管先例，影响全球 AI 竞争格局

## 📈 行业趋势分析

### 1. AI Agent 从办公场景意外延伸至游戏场景，通用能力边界持续扩展

- 展现通用 Agent 能力的无限可能性，也引发"AI代肝"等争议
- Agent 能力的通用性正在超越设计者的初始预期

### 2. 大模型平台旧版本加速淘汰，迁移成为行业常态
- 腾讯混元 46 个旧版本模型今日正式下线，企业必须在 48 小时内完成迁移

- 大模型平台进入快速迭代期，旧版本模型生命周期缩短

### 3. 国产大模型补齐多模态能力，DeepSeek 首次实现图像理解
- DeepSeek 识图模式正式上线，首次补齐多模态能力空白
- 采用"Thinking with Visual Primitives"核心框架
- 虽然人物识别等能力尚不稳定，但标志着从纯文本向全模态迈进
- 国产大模型在多模态领域正在快速追赶海外竞品

### 4. GPT-5.6 即将发布，Agent 能力成为核心竞争维度
- 预计本周（6/22-28）发布，上下文窗口扩展至 150 万 tokens
