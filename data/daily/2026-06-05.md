## 🔴 重要更新

### 1. Kimi Work 开启公测：面向知识工作者的通用型本地 Agent（6月3日）
- **发布方**: 月之暗面
- **核心内容**:
  - 面向知识工作者的通用型本地 Agent，随最新测试版 Mac 和 Windows 客户端推出
  - 只需用自然语言描述目标，即可在电脑上拆解任务、并行执行、调用工具、使用浏览器、创建和整理文件夹
  - 可交付文档、表格、PPT 等工作产物
- **技术内核**:
  - 基于 Kimi Code，每天几十万程序员和 Kimi 全员在用的本地 Coding Agent
  - 提供本地 Agent 基础能力：安装和使用技能(Skill)、运行定时任务
  - 继承在线版 Kimi Agent 的建站、PPT 等专业 Skills 和金融、科研、法律等专业数据库
  - 内置 Kimi WebBridge 方案，能像用户一样使用浏览器
- **Agent 集群能力**:
  - 最高可根据任务复杂度，自主创建包含 300 个子 Agent 的团队
  - 支持处理更复杂、耗时更久的任务
- **开发过程**:
  - Kimi Work 自身由 Kimi Code 深度参与编写
  - 一周内完成 Beta 版 Mac 和 Windows 客户端
  - 累计产出超过 5 万行有效代码，其中 92% 由 AI 自主生成
  - 背后依赖 Kimi K2.6 模型的长程任务执行能力：支持 13 小时连续编码、300 个子 Agent 并行协作、4000 余次自主工具调用
- **应用场景**:
  - 金融场景：调研巴菲特投资策略、生成 Skill、调用专业数据源分析持仓
  - 科研场景：清洗仿真数据集、总结特征规律、绘制学术图表、辅助完成论文
  - 办公场景：读取本地文件、使用浏览器调研订阅数据库、生成深度报告、调用 PPT Skill 输出方案
- **行业意义**: 从 Coding Agent 到 Working Agent，从 TUI 到 GUI，标志着 AI Agent 从"写代码"走向"做工作"

### 2. 智能体落地 2026 上半年：技术狂飙与决策迷茫并行（行业深度）
- **发布方**: 36氪
- **核心观察**:
  - 技术进步速度远超想象，企业进入"亢奋状态"
  - OpenClaw 等新框架带来冲击：开发效率、产品形态、人员结构、软件逻辑全面重写
  - 企业普遍焦虑：技术架构变得太快，已投入成本建设的智能体系统是否要推倒重建
- **新旧架构之辩**:
  - 开放式架构可低成本适配新范式，封闭式架构则面临较大架构压力
  - 客户不关心范式，只看效果；倾向于用新范式做原来做不了的新场景
  - 工作流适合规则固定、流程严谨的场景；多智能体协同适合泛化性强、无法穷举流程的场景
- **客户需求变化**:
  - 业务部门采购积极性大增，甚至超过 IT 部门
  - 不再为裸平台付费，必须是场景引导带基建
  - 预算结构变化：智能体订单量增长 50% 以上
  - ROI 计算深化：引入 FTE 测算法，以核心人工工时替代率衡量
- **落地进展**:
  - 央国企智能体项目成功率约 70%，低于传统 IT 项目
  - 数据与知识质量成为最首要失败原因
  - FDE（现场深度交付）能力成为核心竞争力
  - 智能体从边缘试点走向核心业务
- **行业意义**: 智能体从"演示"走向"生产"，技术狂飙与决策迷茫并行，新旧架构博弈与客户需求升级同步
