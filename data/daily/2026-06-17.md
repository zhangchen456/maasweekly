### 1. 豆包任务模式实测：Skill 机制优先，Agent 落地走向克制（跟进 6/15 报道）

  - **宣传视频生成**：协调代码、图片、视频等不同工具，异常时主动给出替代方案
- **产品定位**:
 - 豆包开始向桌面 Agent 方向迈进，但选择克制路线：有限权限下尽可能完成更多任务
  - 与 Codex、Claude Code、腾讯 WorkBuddy 等竞品形成差异化
- **行业意义**: 国产 AI Agent 正式推向普通用户，Skill 机制成为 Agent 能力扩展的重要路径

## 📈 行业趋势分析

### 1. 美国政府 AI 监管升级，出口管制成为前沿模型发布的不确定性因素
- Anthropic Fable 5/Mythos 5 遭美国政府出口管制封禁仅三天后，GPT-5.6 也面临延迟发布风险
- 美国政府利用出口管制工具处理模型安全问题，给前沿 AI 部署带来新不确定性
- 亚马逊研究人员发现"越狱"漏洞成为监管切入点，但网络安全专家认为这类问题无法彻底修复
- 监管双重标准：GPT 5.5 等竞品同样具备类似能力，但未被冻结
- OpenAI、Google 等厂商也需重新评估发布策略
- 前沿 AI 模型发布面临更大的监管风险，可能改变全球 AI 竞争格局

### 2. 国产大模型快速迭代，开源生态三强格局形成并持续强化
- 智谱 GLM-5.2 全量开放，MIT 协议开源，官方声明直接回应 Anthropic 封禁事件
- MiniMax M3 正式开源，428B 原生多模态 MoE，Hugging Face 权重已上线
- Kimi K2.7 Code 高速版今日上线，输出速度达普通版 5-6 倍，Token 消耗降 30%
- 国产大模型开源三强格局形成：GLM-5.2、MiniMax M3、Kimi K2.7 Code
- 100 万 token 长上下文成为国产旗舰模型标配，与 Gemini 3.5 Pro 持平
- 国产大模型在关键时刻展现开放承诺，强调"前沿智能属于所有人"

### 3. 国产 AI Agent 正式推向普通用户，落地策略趋于克制
- 豆包任务模式全量上线，但选择了一条相对克制的路线
- 不主动获取系统权限，而是优先通过 Skill 机制调用能力
- 实测场景覆盖瑞幸咖啡下单、App 开发、宣传视频生成等
- 权限申请与功能实现的平衡成为 Agent 产品设计的关键
- 对于拥有庞大用户规模的产品来说，克制策略或许更容易落地
- 这条赛道上已经站着 Codex、Claude Code、腾讯 WorkBuddy

### 4. 编程模型进入"高速时代"，速度成为关键用户体验指标
- Kimi K2.7 Code 高速版输出速度达 180-260 Token/s，为普通版的 5-6 倍
- 高速版价格为普通版的 2 倍，性价比显著提升
- 编程场景高频交互特性决定速度本身就是关键用户体验
- 国内大模型厂商纷纷推出高速模型，形成新竞争维度
- Token 消耗优化（K2.7 降低 30%）进一步降低使用成本
