## 🔴 重要更新

### Kimi 发布 WebBridge 浏览器自动化插件（5月15日）
- **发布方**: 月之暗面（Moonshot AI）
- **核心功能**: AI Agent 可像人类一样操作浏览器，支持搜索、点击、输入、滚动、数据提取
- **技术亮点**:
  - 本地优先架构，通过 Chrome DevTools Protocol 运行
  - 所有浏览数据留在本地，不经过云端
  - 支持已登录会话、敏感企业数据
- **兼容性**: 支持 Kimi Code CLI、Claude Code、Cursor、Codex、Hermes
- **底层模型**: Kimi K2.6（SWE-Bench Pro 58.6%，超越 GPT-5.4 的 57.7% 和 Claude Opus 4.6 的 53.4%）
- **获取方式**: Chrome Web Store / [kimi.com/features/webbridge](https://www.kimi.com/features/webbridge)
