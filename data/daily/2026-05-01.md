#### 1. 腾讯混元 Hy3 Preview 登顶 OpenRouter API 调用量榜首

- **生态**: 已接入元宝、ima、WorkBuddy、CodeBuddy 等腾讯产品，支持 OpenClaw、OpenCode、KiloCode 等开源智能体平台

#### 2. 阿里云发布 HappyHorse（快乐小马）AI 视频生成模型
- **时间**: 2026年4月
- **技术**: 150亿参数单流 Transformer 架构，原生音视频同步生成
- **性能**: 单张 H100 生成 5秒 1080P 视频仅需 38 秒，速度达行业主流模型 2-3 倍
- **能力**: 支持中英日韩德法粤 7 种语言精准唇形匹配
- **定价**: 720P 0.9元/秒，1080P 1.6元/秒（会员折扣后低至 0.44元/秒和 0.78元/秒）
- **成绩**: 匿名登顶 Artificial Analysis Video Arena 盲测榜单

#### 3. MiniMax 发布 M2.7 大模型
- **时间**: 2026年4月
- **特性**: 模型自我进化能力，优秀的 Agent Harness 构建
- **能力**: 在 GDPval-AA 的 ELO 得分 1495（开源最高）
- **API**: 提供 M2.7 和 M2.7-highspeed 两个版本，全面支持自动 Cache
- **多芯适配**: Day 0 实现六芯落地（平头哥、华为、海光、沐曦、天数、英伟达）

#### 4. DeepSeek V4 与 Kimi K2.6 双雄对决
- **Kimi K2.6**: 4月20日发布，1T 参数（激活 32B），256K 上下文，业界总参数量最大开源模型
- **DeepSeek V4**: 4月24日发布，开源版本紧随其后
- **市场表现**: 两家包揽全球权威开源模型榜单前两名
- **技术互嵌**: DeepSeek MLA 注意力机制被 Kimi 采用，Kimi 验证的 Muon 优化器被 DeepSeek V4 采用
