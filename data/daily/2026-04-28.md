## 🔥 重点事件详情

### 1. DeepSeek V4 发布 (4月24日)

**模型规格**:
- **V4-Pro**: 1.6T 总参数、49B 激活参数，全球最大开源权重模型
- **V4-Flash**: 284B 总参数、13B 激活参数，轻量高效版本
- **上下文**: 1M token，MIT 开源授权

**技术亮点**:
- 引入 CSA (Compressed Sparse Attention) 和 HCA (Heavily Compressed Attention) 混合注意力机制
- KV Cache 降至 V3.2 的 10%，推理 FLOPs 降至 27%
- 全面适配华为昇腾 950PR 芯片，训练框架从英伟达迁移到华为

**定价策略**:
| 模型 | 输入 ($/1M tokens) | 输出 ($/1M tokens) |
|------|-------------------|-------------------|
| V4-Flash | $0.14 | $0.28 |
| V4-Pro | $1.74 | $3.48 |

**API 迁移通知**:
- `deepseek-chat` 和 `deepseek-reasoner` 将于 2026年7月24日 下线
- 需迁移至 `deepseek-v4-pro` 或 `deepseek-v4-flash`

**融资动态**:
- 启动首次外部融资，目标估值从 $100B 升至 $200-300B
- 腾讯、阿里正洽谈入局

**评测表现**:
- Artificial Analysis Intelligence Index: 52分 (开源第二，仅次于 Kimi K2.6)
- GDPval-AA Agent评测: 1554分 (开源第一)
- SWE-Bench Verified: 优异表现
- 幻觉率: V4-Pro 94%, V4-Flash 96% (仍需注意)

### 2. Kimi K2.6 发布 (月之暗面)

**核心能力**:
- **长周期自主执行**: 支持 300个子Agent、4000个协调步骤
- **Agent Swarm**: 多Agent协同架构
- **基准测试**: Humanity's Last Exam、BrowseComp、SWE-Bench Pro 超越 GPT-5.4

**融资动态**:
- 投前估值 $180B (约1200亿人民币)
- 新一轮 $1B 融资进行中

**技术亮点**:
- 在 CES 2026，黄仁勋使用 DeepSeek 和 Kimi K2-Thinking 作为 GPU 性能基准
- Mac 平台 Qwen3.5-0.8B 通过 Zig 优化，推理速度从 15 tokens/秒 提升至 193 tokens/秒

### 3. 智谱 GLM-5.1 技术论文公开

**架构创新**:
- 引入 DSA (Dynamic Sparse Attention) 稀疏注意力机制
- KV Cache 开销降低 75%，推理速度提升 3倍
- 最大上下文: 202,752 tokens

**异步强化学习基础设施**:
- 将训练引擎和推理引擎解耦
- GPU 利用率从 20-30% 大幅提升
- 支持 Token-in-Token-out (TITO) 流程

**国产芯片适配**:
- 完成华为昇腾、摩尔线程、海光、寒武纪、昆仑芯、沐曦、燧原全栈适配

**评测表现**:
- SWE-bench Verified: 77.8% (开源 SOTA)
- HLE (含工具): 50.4分
- Artificial Analysis Intelligence Index v4.0: 50分 (开源 SOTA)

**CC-Bench-V2**:
- 新推出自动化软件开发评测集
- 前端构建成功率: 98.0%
- 后端 Pass@1: 25.8%

### 4. 腾讯混元 Hy3 preview 发布 (4月23日)

**模型规格**:
- 总参数: 295B，激活参数: 21B
- 上下文: 256K tokens
- 快慢思考融合的 MoE 架构

**性能提升**:
- 首Token延迟降低 54%
- 端到端时长降低 47%
- 清华数学博士资格考试: 国内最高分
- SWE-Bench Verified: 74.4%

**定价**:
- 腾讯云 API 输入: ¥1.2/百万 tokens (同尺寸最低价梯队)
- 个人套餐: ¥28/月

**实测评价**:
- 推理能力: 复杂逻辑拆解强，陷阱识别需加强
- 代码/智能体: 工具调用成熟，任务交付完整性待提升
- 自然对话: AI味明显减弱，文风复刻能力强

**战略意义**:
- 姚顺雨主导技术重构后首份答卷
- 腾讯 AI 从"被动"转向"能打"
