### 4. 腾讯混元 - 开源新版本模型

**事件**: 腾讯开源 Hunyuan-A13B（6月30日）

**关键更新**:
- **模型规格**: 专家混合模型，800亿参数，130亿激活参数
- **双模式推理**:
  - 快速思维模式：简洁高效输出，适用于日常任务
  - 慢速思维模式：支持更深层次的推理步骤，包含反思和回溯，生成更长思维链
- **Agent 强化**: 针对 AI Agent 进行专门强化，设计超过30种智能体指令
  - 组合工具、动作、响应的格式变化，创造出 20000 种格式组合
  - 打造应对不同场景变化的"自适应大脑"
- **性能表现**:
  - AIME2024: 87.3 分（超越 DeepSeek-R1 的 79.8 分）
  - AIME2025: 76.8 分（超越 DeepSeek-R1 的 70 分）
  - Agent 测试 BFCL-V3: 78.3 分（大幅超越 DeepSeek-R1 的 56.9 分）
  - ComplexBench: 61.2 分（大幅超越 DeepSeek-R1 的 41.1 分）
- **架构设计**: 1个共享专家 + 64个细粒度非共享专家，采用 SWiGLU 激活函数和 Grouped-Query Attention
- **开源地址**: HuggingFace 和 GitHub 已开放

**状态**: 🟢 重大开源发布

### 7. Kimi（月之暗面）- Agent 灰度测试

**事件**: Kimi-Researcher Agent 开启灰度测试（6月20日）

**关键更新**:

- **工作流程**:

  - 深入思考：每个任务平均进行 23 步推理
  - 主动搜索：平均规划 74 个关键词，找到 206 个网址，筛选出前 3.2% 高质量内容
  - 调用工具，交付结果：自主调用浏览器、代码等工具，端到端完成交付
- **交付成果**:
  - 万字以上深度研究报告，平均引用约 26 个高质量可溯源信源
  - 可交互、可分享的动态可视化报告（结构化排版、思维导图）
- **性能表现**:
  - HLE 测试 Pass@1: 26.9%（超越 Claude 4 Opus 10.7%、Gemini 2.5 Pro 21.6%）
  - HLE 测试 Pass@4: 40.17%（超越 OpenAI Deep Research 26.6%）
  - xbench DeepSearch 任务: 69% 平均通过率（领先榜单其他模型）

## 七、趋势洞察

### 1. 国产大模型开源生态进入"爆发期"
腾讯开源 Hunyuan-A13B、百度开源文心4.5系列、Kimi K2.7 Code、智谱 GLM-5.2、MiniMax M3 纷纷开源，国产大模型开源生态日益完善。开源模型与闭源模型形成差异化竞争，推动整体技术迭代加速。

### 2. Agent 能力成为大模型竞争新焦点
Kimi-Researcher 开启灰度测试、腾讯 Hunyuan-A13B 针对 Agent 强化（30+ 智能体指令）、硅基流动 Nex-N2-Pro 主打 Agentic Thinking，反映出 Agent 能力已成为大模型竞争的新焦点，从"能回答"向"能执行"演进。

### 3. API 兼容性管理成为平台必修课
DeepSeek 旧 API 接口即将停用（7 月 24 日）、百度千帆 Coding Plan 套餐停止续费（6 月 25 日）、腾讯混元旧模型批量下线，反映出大模型平台快速迭代背景下，API 兼容性管理和迁移引导的重要性日益凸显。

### 4. 视频生成进入"效果+成本"双优化阶段
MiniMax Hailuo 2.3 在提升性能的同时保持价格不变，并推出更便宜的 Fast 版本（降低 50% 成本）。视频生成赛道从"拼效果"进入"效果+成本"双优化阶段，性价比成为核心竞争力。

### 5. 多模态能力成为标配
百度文心4.5系列开源、DeepSeek V4.1 多模态发布、MiniMax 全模态模型布局，多模态能力已成为大模型平台的标配，从单一文本向文本+图像+视频+音频全模态演进。
