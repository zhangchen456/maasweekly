## 🔴 重要更新

### 1. Anthropic 发布 Claude Opus 4.8：动态工作流、可调思考强度、快模式降价（5月28日）
- **发布方**: Anthropic
- **核心亮点**:
  - **动态工作流（Dynamic Workflows）**: Claude Code 研究预览版功能，单任务可协调数百个并行子智能体，完成数十万行代码的大规模代码库迁移任务
  - **投入控制（Effort Control）**: 用户可直接控制 Claude 为任务投入多少"思考资源"，在速度、成本和推理深度之间自行权衡
  - **快速模式大幅降价**: 运行速度提升至常规 2.5 倍，成本仅为前代模型的三分之一
    - Fast Mode 定价：$10/M 输入 + $50/M 输出（原 $30/$150）
    - 常规定价不变：$5/M 输入 + $25/M 输出
- **"诚实度"大幅提升**: 
  - 面对不确定信息时，更倾向主动标记疑点、表达不确定性
  - 允许代码中存在缺陷却未加提示的概率仅为此前模型的四分之一
  - 对齐性评估达到与 Claude Mythos 预览版相媲美的水平
- **测评成绩**:
  - Online-Mind2Web 浏览器智能体基准：84%，优于 Opus 4.7 和 GPT-5.5
  - 长流程任务中保持更稳定的目标一致性和工具调用能力
- **发布节奏**: 较此前代码泄露与业内爆料的"6月中旬左右"提前近两周，Anthropic 正在加速旗舰模型迭代
- **行业意义**: 从"模型能力竞争"进一步迈向"智能体系统竞争"，推动 Claude 从聊天模型向"长期自主执行系统"演进
