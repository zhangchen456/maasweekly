## 一、重要更新摘要

### 🔴 今日头条
1. **OpenAI GPT-5.6 有限预览发布**：6月26日（周五），OpenAI 宣布开始有限预览 GPT-5.6 系列模型，包括旗舰模型 Sol、平衡型模型 Terra 和低成本模型 Luna。Sol 是目前能力最强的模型，在编程、生物学和网络安全任务上都有提升。但初期仅通过 API 和 Codex 向少数可信伙伴和组织开放，相关参与方信息已与美国政府共享。

6. **DeepSeek 旧 API 接口即将停用**：deepseek-chat 与 deepseek-reasoner 两个旧模型名将于 2026 年 7 月 24 日停止使用，当前分别映射至 deepseek-v4-flash 的非思考模式与思考模式。
7. **硅基流动上线 Nex-N2-Pro**：支持 Agentic Thinking、Frontier Coding 和 Long-Horizon Execution，面向真实世界生产力场景。

## 七、趋势洞察

### 1. AI 监管从"硬件管制"扩展到"模型审查"已成定局
OpenAI GPT-5.6 因特朗普政府要求审查而被迫以"有限预览"方式发布，相关参与方信息需与政府共享。这标志着前沿 AI 模型的发布已从"技术竞赛"全面转向"合规竞赛"，模型审查可能成为常态化机制。

### 2. 国产大模型平台"统一入口+聚合服务"趋势深化
百度千帆发布 Token Plan 企业版，聚合 DeepSeek-V4、GLM-5、Kimi-K2.6 等多厂商模型能力；百度文心网站合并升级打造统一超级入口。平台从"单一模型服务"向"多模型聚合服务"转型，降低企业接入门槛。

### 3. 视频生成进入"效果+成本"双优化阶段
MiniMax Hailuo 2.3 在提升性能的同时保持价格不变，并推出更便宜的 Fast 版本（降低 50% 成本）。视频生成赛道从"拼效果"进入"效果+成本"双优化阶段，性价比成为核心竞争力。

### 4. API 兼容性管理成为平台必修课
DeepSeek 旧 API 接口即将停用（7 月 24 日）、百度千帆 Coding Plan 套餐停止续费（6 月 25 日）、腾讯混元旧模型批量下线，反映出大模型平台快速迭代背景下，API 兼容性管理和迁移引导的重要性日益凸显。

### 5. 开源策略持续深化，生态竞争加剧
Kimi K2.7 Code、智谱 GLM-5.2、MiniMax M3 纷纷开源，国产大模型开源生态日益完善。开源模型与闭源模型形成差异化竞争，推动整体技术迭代加速。
