# MaaS 平台周度追踪报告 - 2026-09-22

**报告期次**: 2026-09-22
**追踪周期**: 2026-09-16 ~ 2026-09-22
**数据来源**: 官方信源与站内来源记录

## 一、重要更新摘要

### 🟡 值得关注

1. **Kimi Batch API 开放，托管智能体仍有准入范围**：官方更新日志记录 Batch API 面向全量用户开放；托管智能体 Beta 当前面向国内企业认证用户开放。列表同时出现 Context Caching 全量开放与续期不再收取创建费用的说明。

   证据：[2026-09-16 来源记录](/item/obs_584d2d0e11207d9178106093bdd645ba35d9472abe33ff447a0bbad40f511a2d/) · [官方来源](https://platform.kimi.com/docs/changelog)。

2. **Anthropic Messages API 支持按需压缩会话**：官方文档说明通过 compact-2026-09-04 Beta 请求头和顶层 compaction 参数，可以主动生成签名压缩块，后续以压缩块替换旧消息；也可保留最近轮次原文。对长会话应用，这提供了显式管理上下文的方式，但需要核对模型支持、签名块回传与保留思考的约束。

   证据：[2026-09-16 来源记录](/item/obs_0cfe2284f81351fd00ea3c22db40f92f6b46ce210d412115a4423bcff64c3fb3/) · [官方来源](https://docs.anthropic.com/en/release-notes/api)。

3. **Google Gemini API 增加实时语音模型选项**：官方文档记录 Gemini 3.8 Live 与 Gemini 3.8 Live Extended Thinking 两个实时音频模型的正式可用说明，前者为默认选项，后者面向更强推理需求。实时语音系统应分别测量响应延迟、打断处理和推理质量，本期没有独立延迟或效果测试。

   证据：[2026-09-16 来源记录](/item/obs_354d7aa50473a2d7e27b0b83854d22d225d330bd328dc30eaef9aeb0e40ef4fa/) · [官方来源](https://ai.google.dev/gemini-api/docs/changelog)。

4. **OpenAI 增加组织与项目级 API key 创建控制**：管理员可以只允许服务账号 key、只允许用户所属项目 key，或禁止创建新 key；组织级限制优先于项目设置，现有 key 不受这项创建规则影响。企业集成应核对自动化开通流程的账号类型，避免把禁止新建误认为已撤销现有凭证。

   证据：[2026-09-17 来源记录](/item/obs_37b261f34fa67090b074b120f9aeacdd63d317563028e2ef432dd16cbfa91142/) · [官方来源](https://platform.openai.com/docs/changelog)。

5. **xAI API 更新日志记录 Grok 4.7 上线**：官方文档记录公开 API 模型名 grok-4.7、500k 上下文、文本与图像输入、文本输出，以及按提示长度分档的计费和推理强度选项。Grok 4.7 Fast 当时仅通过 Cursor 与 Grok Build 提供，不属于公开 xAI API 的可调用模型。

   证据：[2026-09-22 来源记录](/item/obs_be81c9cd2a853b249b95074d457a3a1aed4eb7b7d4ed5241beaa31e3bafbc099/) · [官方来源](https://docs.x.ai/docs/release-notes)。
