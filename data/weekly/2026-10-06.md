### 🟡 值得关注

1. **历史补编说明——采集范围与日期口径**：本期于 2026 年 10 月 10 日依据 2026-09-30 至 2026-10-06 的历史采集记录补编。窗口内有 7/7 天 diff；七天均有采集记录。日期表示采集到变化的时间，除非正文另有明确公告日期；不把首次抓取、页面删除、导航调整或抓取失败解释为新品发布、下线或调价。

2. **OpenAI Agents API 增加 computer use**：归档说明 Agents API 可使用 OpenAI 托管浏览器完成任务，网站访问批准与登录由应用处理。这项能力改变了 Agent 与浏览器环境的连接方式，应用仍需实现相应的批准和登录流程；本期没有对真实网站执行任务的效果测试。

   证据：[2026-09-30 归档条目](/item/obs_4791dfded079c1d4e0e1130d3d5165f111a462edb836bf7a65fd7ceac9038e68/) · [官方来源](https://platform.openai.com/docs/changelog)。

3. **Cohere 发布 Embed 5 嵌入模型系列**：更新日志与模型列表记录 Embed 5 Pro/Fast，支持文本、图像及混合文档输入，128k 上下文，并提供多档向量维度与输出类型。对于现有检索系统，迁移涉及重建向量和匹配维度；厂商关于检索质量的说明需要用自己的文档集验证。

   证据：[2026-09-30 归档条目](/item/obs_2df532a4f57ab88af12d65014a2ac3b5c89e9ed0e0398efac67dd386095a8051/) · [官方来源](https://docs.cohere.com/changelog)。

4. **Anthropic 预告 Sonnet 4.5 在 11 月 30 日退役**：归档公告记录 claude-sonnet-4-5-20250929 计划于 2026 年 11 月 30 日在 Claude API 退役，并建议迁移到 Sonnet 5.5。该日期是未来计划；本期不写成已经停止服务。迁移还应结合上期记录的 Sonnet 5.5 请求兼容变化。

   证据：[2026-10-01 归档条目](/item/obs_b430bb7e93094c95e3dcbaa684cab49865b04b24715f4529e84542f0661fa5d8/) · [官方来源](https://docs.anthropic.com/en/release-notes/api)。

5. **xAI 语音转写旧模型改由 2.0 服务**：10 月 3 日采集到的日志说明 grok-voice-transcribe-1.0 于 10 月 2 日结束生命周期，旧 slug 请求路由到 grok-voice-transcribe-2.0，价格保持一致。这里区分公告中的执行日与采集日；应用应同步更新模型配置，并用现有音频样本核对输出格式与质量。

   证据：[2026-10-03 归档条目](/item/obs_3db8a4529be6c9c1a08d2fb870476b85a26ebbfe86f2607b04aa92dc515f2d0d/) · [官方来源](https://docs.x.ai/docs/release-notes)。

6. **MiniMax 将 Preview 模型入口说明改为 M Plan**：模型列表把 M3.1 Flash Preview 的入口描述从 Token Plan 改为 M Plan 与 MiniMax Code。归档能确认入口名称发生修改，但不足以单独证明套餐涨价、权益扩大或按量 API 开放，本期只记录这项范围明确的文档变化。

   证据：[2026-10-01 归档条目](/item/obs_3fd225ab04f787bd68efb780ae24091aceccf3ba8f83ea92078da82a1ca7f87b/) · [官方来源](https://platform.minimaxi.com/docs/guides/models-intro)。
