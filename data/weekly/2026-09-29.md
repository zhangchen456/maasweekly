# MaaS 平台周度追踪报告 - 2026-09-29

**报告期次**: 2026-09-29
**追踪周期**: 2026-09-23 ~ 2026-09-29
**数据来源**: 官方信源与站内来源记录

## 一、重要更新摘要

### 🟡 值得关注

1. **Anthropic 发布 Sonnet 5.5，迁移包含请求兼容变化**：更新日志记录 claude-sonnet-5-5 发布，并单列从 Sonnet 5 迁移的变化：部分思考配置需要改写，强制工具选择可能返回 400，旧版 computer use 工具及部分 advisor 组合不再接受。直接替换模型名可能造成请求失败，应先跑思考、工具与跨账号消息的回归用例。

   证据：[2026-09-29 来源记录](/item/obs_8b6acc99991635cc75062cdb7cc53727b5c73e2827723c5426f68fb9715faf13/) · [官方来源](https://docs.anthropic.com/en/release-notes/api)。

2. **Google Gemini API 增加两款正式 TTS 模型**：官方文档记录 gemini-3.8-flash-lite-tts 与 gemini-3.8-flash-tts 正式发布，分别面向高吞吐语音合成与创作级语音表现；模型列表建议从旧 TTS 预览版本迁移。模型选择要结合语种、音色和吞吐要求。

   证据：[2026-09-24 来源记录](/item/obs_38ab000e3d30fac1174b3b5b0060aae6c7a0d4bc226a2e178f8d3a87236f9b96/) · [官方来源](https://ai.google.dev/gemini-api/docs/changelog)。

3. **Anthropic 缓存诊断结束 Beta**：官方文档说明缓存诊断不再要求 Beta 请求头；请求中的 diagnostics 对象仍需显式传入，响应会包含 diagnostics 字段，未开启时为 null。接入代码要处理 null，并在需要连续比较的各轮请求中启用诊断，不能依赖只传旧请求头来保存指纹。

   证据：[2026-09-25 来源记录](/item/obs_7cc176334cc36722cc1947c05eca4eaa666180b332c75a3c9c4f82c666a78e90/) · [官方来源](https://docs.anthropic.com/en/release-notes/api)。

4. **MiniMax M3.1 Flash Preview 的入口有限**：模型页新增 MiniMax-M3.1-Flash-Preview，描述为原生多模态、1M 上下文、思考深度可调的编程模型；当期说明暂时仅通过 Token Plan 与 MiniMax Code 提供。不能据此推断所有按量 API 账号已经可用，访问入口和套餐范围需分别核对。

   证据：[2026-09-28 来源记录](/item/obs_41e8441daba198062937687c7ef96db09ec670ad4573e445cca97ab1c4727985/) · [官方来源](https://platform.minimaxi.com/docs/guides/models-intro)。

5. **硅基流动公告预告 9 月 30 日下线 ERNIE Image Turbo**：窗口末更新日志新增 ERNIE-Image-Turbo 下线公告，并写明计划于 9 月 30 日处理。有相关调用的应用应提前准备替代模型。

   证据：[2026-09-29 来源记录](/item/obs_552346278fcfb6c703fc76f94a72f52b29e31bce4cea8d3d688979315ca11e9e/) · [官方来源](https://docs.siliconflow.cn/docs/release-notes/overview)。
