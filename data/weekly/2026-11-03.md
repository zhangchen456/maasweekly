## 一、重要更新摘要

### 🟡 值得关注

1. **Claude用量与费用统计推出新接口**：官方10月29日公告推出Usage and Cost Analytics API测试版，旧统计接口继续受支持。已有账单分析无需因为“legacy”标签立即停用，但迁移前应核对分组维度和权限。官方10月28日另将第一方Messages与Token Counting接口的请求体上限从32 MB提高到128 MB；这不是上下文窗口扩大。

   证据：[10月30日来源记录](/item/obs_f9a917948f0f47fd034a6974fd0840ab0937367565e7adbc4b936aa67d784e3e/) · [官方日志](https://platform.claude.com/docs/en/release-notes/overview) · [接口说明](https://platform.claude.com/docs/en/manage-claude/usage-cost-analytics-api)。

2. **Opus 4.8快速模式有明确迁移期限**：官方10月30日宣布弃用该模式，计划11月30日移除。届时向claude-opus-4-8发送speed: "fast"将报错；需要继续使用快速模式的应用应评估迁移到Opus 5.5。本条不表示Opus 4.8全部服务在同日下线。

   证据：[10月31日来源记录](/item/obs_da8e8b631dab03ddd5e87b87a69b4b7754873d9763b9d4eaf854b61b41f53752/) · [官方快速模式说明](https://platform.claude.com/docs/en/build-with-claude/fast-mode)。

3. **Message threads减少重复上传对话**：官方11月2日公告开放测试，由服务器保留会话，后续请求只发送新增消息。线程在最后一次请求5分钟后过期，最后使用后不超过1小时删除。长对话应用需要处理过期后的恢复；不能把这个机制当成长久记忆或直接推算Token费用下降。

   证据：[11月3日来源记录](/item/obs_1286132156d64077334b5bd77066ce831362a7dbcee594dd3f71ea249d597490/) · [官方线程说明](https://platform.claude.com/docs/en/build-with-claude/message-threads)。

4. **Gemini增加命令行接入并推进Computer Use正式可用**：本期观察到Gemini API CLI（gemini-api）测试版公告，面向脚本、CI和编码代理；另观察到Computer Use在Interactions与GenerateContent接口转为正式可用。两项变化对应接入方式和工具状态，不构成模型价格或效果提升的证明。

   证据：[10月29日CLI记录](/item/obs_bac16a946d9feafc83244304b58507dabfc05c07e679f714bc72b4ae031e22c3/) · [10月31日Computer Use记录](/item/obs_67f198c2c8e4700940b48987501c0172c716822bdbb2a197044982b6bd4eb1f1/) · [官方日志](https://ai.google.dev/gemini-api/docs/changelog)。

## 二、各平台详细追踪

### 1. Anthropic

**状态**: 🟡 有已核实的接口变化及迁移节点

**本周动态**:

- 统计接口迁移应先并行比对相同周期的结果，再切换生产账单报表；“旧接口仍支持”与“新接口处于测试”需要同时考虑。
- 快速模式迁移应检查请求中的模型ID和speed参数，并针对延迟、输出及失败重试做回归。迁移期限见第五节。
- Message threads接入应保留会话过期的恢复路径，并核对数据留存设置；不要把短时线程保存等同于持久存储。
- 本节为编辑建议；接口事实和来源见第一节，不代表本站已完成真实业务负载测试。

### 2. Google Gemini API

**状态**: 🟡 有命令行接入与工具状态更新

**本周动态**:

- CLI适合先在隔离脚本中验证认证、错误码和输出解析，再接入CI；Computer Use应先验证目标应用与权限边界。
- 本期证据确认的是官方公告出现及正式可用状态，不将“正式可用”解释为所有模型、地区或调用条件都相同。具体接入以对应官方文档为准。
