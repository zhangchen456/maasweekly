## 一、重要更新摘要

### 🔴 本周头条

1. **DeepSeek V4.1 灰度测试泄露，代码能力"天差地别"提升**
   - 6月15日，DeepSeek 网页版疑似上架 V4.1 Flash 模型，已进入灰度测试阶段。网友实测称代码能力"天差地别"的提升。知识截止日期从 2025 年 5 月更新至 2026 年 1 月。金门大桥 three.js 场景测试显示 SVG 生成、三维场景构建效果显著提升。多模态能力增强不明显，可能不在本次更新重点。延续"先 Flash 后 Pro"发布策略，端午节前后正式发布概率高。

2. **Gemini 3.5 Pro 全网首曝，编程追平 GPT-5.5，谷歌 Agent 战略升级**
   - 6月16日，代号「Cappuccino」的 Gemini 3.5 Pro 检查点已开始产出，从原传 3.2 直接跳级到 3.5。3.5 Flash 在 SVG 生成、交互式 3D 编码和动画处理上已超过 3.1 Pro。3.2 Flash 在编码和推理上达到 GPT-5.5 的 92%，成本便宜 15-20 倍。Gemini Spark BETA 定位"24/7 数字生活管家"，24 小时全时运转处理收件箱、在线任务、多步骤工作流。但性能大致落在 GPT-5.5 档位，距离 Mythos 还有明显差距。

3. **GPT-5.6 预计 6 月底发布，OpenAI 首席科学家确认"有意义的跃升"**
   - 6月16日，OpenAI 首席科学家确认 GPT-5.6 是"有意义的跃升"（meaningful leap）。预计 6 月底发布，Polymarket 给出 89% 概率。GPT-5.2 系列已于 6 月 12 日从 ChatGPT 退役为 5.6 铺路。内部代号包括 ember-alpha、beacon-alpha 等。受 Anthropic 遭封禁影响，GPT-5.6 发布面临更大监管不确定性。特朗普签署行政命令要求企业在公开发布最新模型前须向政府开放最长 30 天网络安全测试窗口。

4. **Kimi K2.7 Code 高速版正式上线，输出速度达普通版 5-6 倍**
   - 6月15日，Kimi K2.7 Code 高速版（kimi-k2.7-code-highspeed）正式上线。常规编程场景输出速度约 180 Token/s，短上下文场景可达 260 Token/s。高速版价格为普通版 2 倍。Token 消耗减少 30%（相比 K2.6），Kimi Code Bench v2 提升 21.8%。编程模型进入"高速时代"。

5. **智谱 GLM-5.2 全量开放并开源，官方声明回应 Anthropic 封禁**
   - 6月13日 17:21 面向 GLM Coding Plan 全量用户开放（Lite/Pro/Max/团队版）。6月17日官方声明强调开源承诺："前沿智能不应只属于少数人，也不应被少数规则随时收回。" 直接回应 Anthropic Fable 5/Mythos 5 遭美国政府出口管制封禁事件。支持真正可用的 1M 上下文，能在无外部依赖下生成 900+ 行可运行 SVG 机械钟代码，能在纯浏览器环境复刻 Excel 核心体验。MIT 协议开源，下周开放 API。

6. **豆包任务模式全量上线，Skill 机制优先的克制 Agent 策略**
   - 豆包 App 任务模式全量上线，选择克制路线：不主动获取系统权限，优先通过 Skill 机制调用能力。实测覆盖瑞幸咖啡下单（成功安装 My Coffee Skill）、App 开发（生成完整产品方案、UI 设计稿、SwiftUI 代码）、宣传视频生成等场景。与 Codex、Claude Code、腾讯 WorkBuddy 形成差异化。

## 四、趋势洞察

1. **美国 AI 监管升级，出口管制成为前沿模型发布的不确定性因素**
   - Anthropic Fable 5/Mythos 5 遭封禁后，GPT-5.6 也面临延迟发布风险。特朗普签署行政命令要求企业发布最新模型前向政府开放 30 天网络安全测试窗口。出口管制工具被用于模型安全监管，给前沿 AI 部署带来新不确定性。监管双重标准问题凸显：GPT-5.5 等竞品同样具备类似能力但未被冻结。OpenAI、Google 等厂商需重新评估发布策略，可能改变全球 AI 竞争格局。

2. **国产大模型快速迭代，开源三强格局持续强化，智谱直接回应封禁事件**
   - 智谱 GLM-5.2 全量开放，MIT 协议开源，官方声明直接回应 Anthropic 封禁——"前沿智能不应只属于少数人，也不应被少数规则随时收回"。MiniMax M3 Hugging Face 权重上线，API 定价公布。Kimi K2.7 Code 高速版正式上线。国产开源三强格局（GLM-5.2、MiniMax M3、Kimi K2.7 Code）在 Anthropic 遭封禁窗口期展现开放承诺，国产大模型在关键时刻填补前沿模型不可用的空白。

3. **海外 AI 御三家竞争白热化，Agent 成为新战场**
   - Gemini 3.5 Pro 预计本周发布，Spark Agent 升级为 24/7 数字生活管家。GPT-5.6 预计 6 月底发布，首席科学家确认"有意义的跃升"。Anthropic 遭封禁为竞争对手创造窗口期。Agent 能力成为三大平台竞争新焦点：Gemini Spark vs OpenAI 24/7 Agent vs Anthropic Conway。但性能差距仍在，Gemini 3.5 Pro 大致落在 GPT-5.5 档位，距离 Mythos 还有明显差距。

4. **DeepSeek V4.1 灰度测试泄露，"先 Flash 后 Pro" 策略延续**
   - DeepSeek 网页版疑似上架 V4.1 Flash，代码能力"天差地别"提升，知识截止日期更新至 2026 年 1 月。延续春节发 R1、8 月发 V3.1 的节奏，端午节前后发布概率高。Flash 及 Pro 版本基模能力不弱，主要缺后训练调优。多模态能力可能延后，因算力需求与低价策略之间存在矛盾。

5. **国产 AI Agent 正式推向普通用户，落地策略趋于克制**
   - 豆包任务模式全量上线，选择克制路线：不主动获取系统权限，优先通过 Skill 机制调用能力。实测覆盖瑞幸咖啡下单、App 开发、宣传视频生成等。权限申请与功能实现的平衡成为 Agent 产品设计关键。对于拥有庞大用户规模的产品，克制策略或许更容易落地。与 Codex、Claude Code、腾讯 WorkBuddy 等竞品形成差异化。
