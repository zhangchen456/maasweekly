# MaaS 平台周度追踪报告 - 2026-10-27

**报告期次**: 2026-10-27
**追踪周期**: 2026-10-21 ~ 2026-10-27
**数据来源**: 官方更新日志与站内来源记录

本期于 2026-10-31 补刊，覆盖上述完整观察周期。观察日期不自动等于产品发布日期；未覆盖的平台不表示没有更新。本文基于截至 10 月 31 日保留的来源记录，不补造漏刊期间的出版日期。

## 一、重要更新摘要

### 🟡 值得关注

1. **Decisions API 转为正式可用**：更新日志说明 Decisions API 与 gpt-6-luna 正式可用，单次请求上限从公开测试的 200 个问题提高到 400 个，并支持 input_json、问题中的图片及共享输入缓存。已有调用应核对测试期到正式版的变更，再验证批量任务的错误处理。

   证据：[2026-10-23 来源记录](/item/obs_8fc8dc29ff7fcb53f1e86ccbfcb0717bc157dcf7681b4004d68ba465b155c5f7/) · [官方来源](https://platform.openai.com/docs/changelog)。

2. **新增 GPT-6.1 Terra**：官方日志新增 gpt-6.1-terra，定位涉及视觉推理、计算机操作与写作。这里仅确认模型和迁移指南的出现，不将厂商描述当作独立能力评测，也不据此推断其价格。

   证据：[2026-10-27 来源记录](/item/obs_c64ae8c43a69ef60392c6baae548b8f137ab89131cae85ef20a6a6a2fe1dfced/) · [官方来源](https://platform.openai.com/docs/changelog)。

3. **Google Cloud 新增 Anthropic 托管接入**：日志记录 Claude Models on Google Cloud（Anthropic managed）：由 Anthropic 运营 Claude API，经 Google Cloud 项目访问，IAM 管理权限，Marketplace 负责计费。Opus 5.5 fast mode 也列入该入口的支持范围。采购与接入时应明确托管方、权限和账单入口，不能直接套用其他渠道的报价。

   证据：[2026-10-23 来源记录](/item/obs_81b6a2b569e315ec1ac6c98fef14690b019fec1d1d4c005ad30335a52d892c43/) · [官方来源](https://docs.anthropic.com/en/release-notes/api)。

4. **新付费项目默认存储 Generate Content 请求**：观察到的日志说明，新建付费项目的 Generate Content API 请求默认开启存储，既有项目维持原设置。文档给出单次请求 store=false 及控制台关闭日志两种退出方式。新项目上线前应检查实际配置；本期不据此推断存储期限或训练用途。

   证据：[2026-10-27 来源记录](/item/obs_b54a40b476d73376ceb2529637554de63875f8006abeb7b0fb3f6ac69c0cc097/) · [官方来源](https://ai.google.dev/gemini-api/docs/changelog)。

5. **相同模型 ID 背后的版本升级**：平台公告说明，2026-10-21 已把 deepseek-ai/DeepSeek-V4.1-Flash 升级到 1017 版本，调用 ID 保持不变。无需改名不代表输出行为必然相同；依赖固定响应格式的应用应重跑回归并记录实际服务版本。本条于 10 月 22 日被本站观察到。

   证据：[2026-10-22 来源记录](/item/obs_0a27fa5a4314ef495e6cda07131597e19e79f818abdedfb25df1ad9176a3feb4/) · [官方来源](https://docs.siliconflow.cn/docs/release-notes/overview)。
